# 3method 交易说明

本文说明如何把当前 method2 CTA + 独立 lot 动态 ATR 平仓策略转换成实盘前 dry-run 委托意图。当前目录只保存研究和回测产物，不直接连接券商下单。

## 每个采样点要做什么

1. 只使用已经完成的分钟 bar 生成特征和分数，不能读取当前未完成 bar 或未来行情。
2. 使用周度股票池：本周股票池由上一交易周高波动 top300 生成。
3. 对股票池内股票计算 `cta_trend_breakout_score`。
4. 过滤掉分数低于 `0.5529991269111634` 的股票。
5. 在剩余股票中按分数从高到低选择 top5。
6. 对 top5 中当前没有持仓 lot 的股票，可以新开仓。
7. 对 top5 中已有持仓 lot 的股票，只有在最新买入日期早于当前交易日时，才允许再开一个新 lot。
8. 每个新 lot 的目标买入金额是当前总资产的 `10%`，不是可用现金的 `10%`。
9. 买入股数按 100 股整数手向下取整；如果现金不足，继续向下缩减，不能加杠杆。
10. 已有 lot 每个采样点单独检查退出条件；满足 T+1 且触发动态 ATR 止损后整笔卖出该 lot。

## 买入触发条件

买入必须同时满足：

- 股票在本周“上一周高波动 top300”股票池内。
- `cta_trend_breakout_score >= 0.5529991269111634`。
- 当前采样点按 `cta_trend_breakout_score` 排名进入 top5。
- 该股票没有当天新开的 active lot；如果已有 lot，必须是前一交易日或更早买入，才允许加仓。
- 不触发实盘风控黑名单、ST、退市风险、停牌、涨停不可买、成交额不足、账户可用资金不足等限制。

## 平仓触发条件

当前验证集选中的规则是：

`atr_initial2_trail4_atr240`

每个 lot 独立计算：

- 入场初始止损价：`买入价 - 2 * 入场时 ATR240`。
- ATR 移动止损价：`持仓后最高价 - 4 * 当前 ATR240`。
- 当前收盘价小于等于上述更严格的止损价时，触发卖出。
- 当天买入的 lot 不允许当天卖出，必须满足 T+1。

注意：股票掉出当前 top5 或掉出当前目标组合，不是平仓条件。平仓只由该 lot 自己的动态止损条件和 T+1 状态决定。

## 委托前检查

买入前至少检查：

- 是否停牌。
- 是否涨停或接近涨停导致无法合理成交。
- 是否 ST、退市整理、风险警示或在人工黑名单中。
- 当日成交额和盘口深度是否足够。
- 单票委托金额是否超过账户风控上限。
- 目标买入金额是否超过当前总资产 `10%`。
- 买入后总暴露是否超过组合层面的最大暴露限制。

卖出前至少检查：

- lot 是否满足 T+1。
- 是否跌停或停牌导致无法卖出。
- 可卖股数是否足够。
- 卖出后是否正确释放该 lot，而不是错误影响同股其他 lot。

## 不要做的事

- 不要同时把 method1 和 3method 当成两个独立 alpha 加倍配仓。
- 不要读取历史测试集预测文件来生成实盘信号。
- 不要因为测试集表现好就回头改入场阈值、topN、ATR 参数或股票池规则。
- 不要在没有涨跌停、停牌、容量和冲击成本保护的情况下直接实盘放大。

## 推荐 dry-run 输出

实盘前的委托意图文件建议至少包含：

- `signal_datetime`：信号时间。
- `execution_datetime`：计划执行时间。
- `symbol`：股票代码。
- `side`：买入或卖出。
- `lot_id`：买入时新生成，卖出时引用已有 lot。
- `shares`：股数，必须是 100 的整数倍。
- `target_value`：按总资产 10% 计算的目标金额。
- `estimated_price`：估算成交价。
- `trigger_reason`：买入或卖出触发原因。
- `risk_checks`：停牌、涨跌停、ST、成交额、黑名单、T+1 等检查结果。
