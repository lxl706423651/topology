## 核心结论

- method2 当前和 method1 高度重合，不应把 method1 和 method2 当成两个独立策略加倍配仓。
- 买入事件按“交易时间 + 股票代码”统计，method1 口径重合率为 `98.39%`，method2 口径重合率为 `96.83%`。
- 已平仓 lot 按“股票 + 买入时间 + 卖出时间”统计，method1 口径重合率为 `98.38%`，method2 口径重合率为 `96.81%`。
- 每个采样点持仓股票集合的平均 Jaccard 重合度为 `0.982812`，中位数为 `1.000000`。
- 两个策略测试集 period return 相关系数为 `0.997409`，累计收益曲线相关系数为 `0.999947`。

因此，3method 当前应被理解为“method1 核心 XGBoost alpha 的 CTA 包装版本 + 动态 ATR 平仓执行方案”，不是独立收益源。

## 策略规则

- 股票池：每周使用上一周高波动 top300 股票。
- 入场分数：`cta_trend_breakout_score`。
- 入场门控：分数必须不低于 `0.5529991269111634`。
- 入场排序：每个采样点最多买入 top5。
- 买入金额：每次新 lot 按当前总资产 `10%` 计算目标买入金额；现金不足时向下缩减，不能加杠杆。
- 加仓：同一股票如果后续交易日仍在 top5 且有现金，可以再开一个新 lot。
- 平仓规则：验证集选中 `atr_initial2_trail4_atr240`。
- 平仓含义：入场初始止损为买入价减 `2 * 入场 ATR240`；移动止损为持仓后最高价减 `4 * 当前 ATR240`；两个止损价同时存在时使用更严格的一个。
- lot 独立性：同一股票不同买入批次拥有不同买入价、入场 ATR、最高价和 T+1 状态，单独判断平仓。
- 交易约束：A 股 long-only、不能做空、不能加杠杆、T+1、100 股整数手。
- 费用：佣金万八、卖出印花税 `0.0005`、过户费 `0.00001`、免 5。
