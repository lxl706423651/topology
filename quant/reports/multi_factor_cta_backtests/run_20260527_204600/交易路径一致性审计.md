# 交易路径一致性审计

- 审计目录：`reports/multi_factor_cta_backtests/run_20260527_204600`。
- 审计目的：判断不同命名策略是否真正产生不同成交序列，避免把同一条路径误当成多个独立 alpha。
- 策略数量：`2`。
- 去重后的可执行交易路径数量：`1`。
- 是否存在重复交易路径：`True`。
- `test_equity_curve.csv`：两个策略完全一致。
- `test_trade_events.csv`：两个策略完全一致。
- `test_holdings.csv`：股票、时间、价格、股数、入场/退出金额和规则一致；只有 `prediction` 解释字段不同。
- `test_round_trips.csv`：买入、卖出、股数、成本、净收益和收益率一致；只有 `买入预测分(prediction)` 解释字段不同。
- 结论：这两个 CTA 命名策略在当前规则下只有 1 条可执行交易路径，不能作为两个独立策略叠加配仓。
