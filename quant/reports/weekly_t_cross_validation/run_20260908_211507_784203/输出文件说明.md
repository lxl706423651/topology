# 输出文件说明

final_report.md是主报告；annual_summary.csv/test_metrics.csv是年度比较；test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv为各年独立结果带test_year汇总。test_return_curve.png/测试集收益曲线.png是图；validation_rule_metrics.csv是内部选择。

每个year目录保存weekly_predictions.csv全部候选预测、weekly_selections.csv前100、t_predictions.csv和t_decisions.csv盘中预测/请求、baseline_trade_events.csv共同基准成交、daily_inventory_audit.csv库存、blocked_orders.csv受阻单、weekly_increment.csv周增量、execution_audit.json成交检查、selected_rule.json事前冻结规则、split.json年度协议和标准结果CSV。validation_candidate_audits保留每组不同决策的真实受阻单和库存失败；分批恢复在test_round_trips.csv中以相同pair_id的多个fragment_id记录，不应把片段数当完整做T次数。各model目录保存模型、特征和训练来源；inner开头表示只用于内部参数选择。

resolved_config.json、data_manifest.json、recovery_manifest.json（启用尾盘分钟时）、research_protocol.json、split_audit.csv、source_hashes.json和source_snapshot/用于复现；goal_evaluation.json记录事前净增益标准是否满足。所有旧报告保留。
