# 输出文件说明

annual_summary.csv/test_metrics.csv 保存年度账目、真实配对、已知持仓时钟分母及覆盖率；enabled/t_enabled 和 t_has_actual_trades 分别表示规则启用与真实首腿成交。

frequency_comparison_v9.csv 保存v9既有结果对照、共同日期数量和逐日基准差；validation_summary.json/frequency_reporting_status.json/goal_evaluation.json 仅报告，不控制交易。摘要记录对照输入SHA和事前已选候选，validation_rule_metrics.csv保留所有内层候选，不由报告重选。

test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv、daily_inventory_audit.csv、blocked_orders.csv、baseline_trade_events.csv、weekly_entry_plans.csv、base_plan_mismatches.csv按test_year合并独立年度原始结果。weekly_increment.csv先各年内作周权益差分。

test_return_curve.png/测试集收益曲线.png和t_increment_curve.png复用实际账目绘图，不跨年拼接账户。T手续费/滑点按全部T成交腿统计，realized_pair_*按已恢复片段统计；未恢复首腿费用与剩余仓位估值不能遗漏。
