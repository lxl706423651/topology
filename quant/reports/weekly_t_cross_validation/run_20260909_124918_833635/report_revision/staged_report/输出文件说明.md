# 输出文件说明

final_report.md：主动启用后的真实年度收益、T次数、费用及执行失败；annual_summary.csv/test_metrics.csv：同一年度汇总，t_enabled与t_has_actual_trades分别表示启用和实际成交。统计列保留为参考。

test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv、baseline_trade_events.csv、daily_inventory_audit.csv、blocked_orders.csv、weekly_entry_plans.csv、base_plan_mismatches.csv按test_year合并各独立账户；weekly_increment.csv先各年内作周权益差分。

test_return_curve.png/测试集收益曲线.png含持有及主动账户收益和净增量，t_increment_curve.png单列净增量。goal_evaluation.json/active_reporting_status.json只报告收益参考与执行状态，不控制启用或选参。

validation_rule_metrics.csv保留原内部候选统计及本轮选择记录；year_*/selected_rule.json为本轮主动规则，t_model/是对应源核心模型副本，selected_support.json为同周期核心支持域。year_*还保存原始预测、请求、成交/库存/失败表、execution_audit.json及frozen_baseline_audit.json。源模型、数据、上下文和代码身份由入口manifest记录。

T实际手续费/滑点按全部T成交腿统计；realized_pair_*仅按已恢复片段分摊统计。未完成配对的费用不能遗漏，片段净利与含遗留仓位估值的账户净增量不得混为一项。
