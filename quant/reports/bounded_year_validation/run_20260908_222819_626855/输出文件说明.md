# 训练阶段文件说明

先看final_report.md（内部验证结果），不能当成外层测试成绩。

- 研究结论.md：最新中文结果，区分折名与测试年收益，解释2026实际拟合、具体策略、修正内容及限制。
- 外层晋级说明.md：训练刚启动、首折规则未产生时记录的人工执行条件；本轮未通过，不运行正式外层。
- bounded_source_audit/：每次审计独立目录，包含真实拟合来源核对.csv、中文结论及自身文件说明；重建20模型实际训练行，不读外层收益。
- training_integrity_audit/：模型重载/列序、入围门槛、配置/源码/模型/规则哈希及拟合日期摘要审计。
- resolved_config.yaml：多层合并配置、标签期限及费用，测试只能读取本文件。
- research_protocol.json：候选设计、目标、源码校验、包版本和外层未使用声明。
- source_snapshot/：冻结前源码快照；data_metadata.json：三种缓存路径与行数。
- folds.json、split_audit.csv：日期切片、每模型拟合年份与标签终点。
- frozen_before_test.json：四折模型/规则校验和及时间，evaluate的输入。
- 年份/entry_*.json、exit_model.json：开仓/继续持仓模型；输出单位为基点。
- 年份/entry_feature_schema.json、exit_feature_schema.json：模型输入列序及退出中文定义。
- 年份/model_feature_manifest.csv：拟合阶段覆盖率、相关性、是否入模和中文因子解释。
- 年份/model_metadata.json、selected_rules.json：模型参数、训练行数、3/5日标签期限、规则及选参原因。
- 年份/training_rule_metrics.csv：校准候选；validation_rule_metrics.csv：内部验证入围候选；selection_segment_metrics.csv：每片段明细。

尚无test_*文件或测试图。只有执行冻结evaluate后才生成真实外层曲线和逐笔成交，不能用训练图冒充。

- training_report.md：原内部报告归档，外层报告不能覆盖。
- 年份/feature_source_audit.csv：外层排除后的内部可用候选来源摘要，包括校准/验证，不是实际核心拟合；核心另有同年来源条件，证据见bounded_source_audit。signal_year=信号年、rows=候选行数、first_source=最早来源、first_signal/last_signal=首末信号，随其他表冻结。
