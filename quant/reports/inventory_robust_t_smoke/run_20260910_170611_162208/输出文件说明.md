# 固定底仓报告文件

- annual_summary.csv、年度.csv、test_metrics.csv：原始成本/账户双口径、手数、覆盖与失败。
- per_stock_cost_reduction.csv：全部底仓股票，包括零T；原始成本、人工加仓、净价差与贡献集中度。
- t_pair_lot_summary.csv：每个首腿pair的原股数、完整状态、配对手、恢复片段及费用净額。
- daily_frequency_coverage.csv：全市场日历中包括零成交日的配对手数及旧股/活动股票日。
- position_amount_audit.csv：实际自动建仓金额区间与人工加仓例外、失败尝试。
- test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv、daily_inventory_audit.csv、baseline_trade_events.csv：原账户记录按年合并。
- goal_evaluation.json：各年5%/金额/库存分别验收，未量化手数不判整体达成，也不控制开启。
- test_return_curve.png、测试集收益曲线.png：各年独立账户及T人民币净增量。

- first_leg_exit_side_audit.csv：原到达报价复查；取消和通过请求不等于实际成交组。
- guard_summary.csv/json：复查、取消、股票日和真实首腿分列。
- selected_robust_rules.csv、inventory_robust_summary.json：v17六个新Huber模型、固定alpha、原矩阵/标签身份合同及来源。
- planned_horizon_summary.csv：已锁存pair的20/40/60原计划期限计数；不能把恢复片段重复计组。
- exit_decisions.csv、dynamic_exit_summary.csv/json：每组首次锁存与真实恢复语义，参考评分不等于账户利润。
