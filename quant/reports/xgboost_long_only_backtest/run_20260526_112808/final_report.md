# XGBoost A 股 Long-Only 回测报告

## 数据与切分

- 训练集：`datetime < 2025-05-01`。内部验证集从 `2024-11-01` 开始，仍然完全位于训练期内。
- 测试集：`datetime >= 2025-05-01`。
- 股票池：8 只稳定沪深 300 股票，来源为 `/data/lxl/seed-emulator/topology/quant/reports/stable_hs300_factor_correlation/run_20260518_223759/stable_hs300_symbols.csv`。
- 使用原始字段：`datetime`、`symbol`、`open`、`high`、`low`、`close`、`volume`、`amount`。
- 当前严格训练期特征清单包含 156 个模型特征，来自 156 个基础因子。

## 防未来函数控制

- 因子生成使用 `quant_backtest.factor_library`；单股票 rolling、lag、pct_change、趋势、波动率、流动性等特征只使用当前及历史已完成 bar。
- 截面 rank 只在同一个 `datetime` 内按当时可交易股票横截面计算。
- 标签是带交易延迟的未来收益：bar t 生成特征和信号，t+1 close 入场，持有 24 根 bar 后退出。
- 内部训练集会排除标签退出时间跨过验证集起点的样本；最终训练集会排除标签退出时间跨过切分日的样本。
- XGBoost 拟合、组合规则选择、特征筛选都只使用训练期或训练期内部验证集。
- 测试集用于最终预测和评估。

## 模型与交易策略

- 模型：`XGBRegressor`，固定参数保存在 `model_metadata.json`。
- 训练目标：同一时间截面的带交易延迟未来收益 rank。
- 策略：按预测分数排序，执行 long-only 整数手规则 `top_n_2p0_hold_2_exposure_1p0`。
- 做空：禁止。杠杆：禁止。目标总多头仓位：`1.0`。
- 调仓：每 `2` 个采样周期调仓一次；每个采样周期为 `24` 根 bar。
- 整数手：买入向下取整到 `100` 股整数手，初始资金 `1000000.0`。
- 交易成本：所有税费合计按成交金额 `0.0001` 计算；滑点设为 0。
- T+1：当天买入的股票当天不能卖出，下一交易日才允许平仓或减仓。
- 尚未完整建模：涨跌停无法成交、ST/退市、最低佣金、冲击成本和历史点时成分股。
