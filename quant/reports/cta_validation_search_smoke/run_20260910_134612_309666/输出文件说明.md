# 输出文件说明

架构：同一规则用于三段固定内部验证，每段从各自之前训练的模型推断。

- final_report.md：生成的中文总报告与三个验证收益图。
- validation_rule_metrics.csv：所有候选逐折真实账户指标。
- candidate_summary.csv：最低折夏普、各年夏普、全部达标标记，不删除失败候选。
- selected_validation_metrics.csv：所选共同规则的标准入口回放结果。
- validation_年份/：该验证区间曲线、逐笔成交、部分平仓、期末持仓、拒单及独立账户审计；兼容test_文件名仅代表内部验证，不是2026。
- protocol.json/resolved_config.yaml：本阶段研究配置、候选全集、固定区间与模型指纹。
- prediction_cache_manifest.json：复用验证预测的内容指纹与数据来源。
- selected_rule.json：同一共同策略，不能按年份事后替换。
- fast_engine_parity.json：加速与原完整入口的逐折一致性证据。
- 根目录test_文件和收益图：最弱验证折的兼容别名，年份以总报告为准，不是2026测试。
- execution_config.yaml：真实费用/仓位/ATR合同快照；source_hashes.json/source_snapshot：实际源码及配置指纹和副本；selected_before_replay.json：标准回放前规则指纹。
- summary.json：目标是否全部达到；未达到时目标保持活动。
- search_source.py：本轮研究源码快照，不是独立可执行入口。
