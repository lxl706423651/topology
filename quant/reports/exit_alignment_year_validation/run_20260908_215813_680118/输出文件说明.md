# 训练阶段文件说明

- 研究结论.md：最新中文结论、四折内部筛选、独立批次规则、未进入正式外层的原因；没有测试业绩。
- 外层晋级说明.md：首折选择前记录的人工晋级约束，至少一种方法四折内部全部启用才安排外层。
- alignment_comparison_audit/：独立审计的每次副本，包含原模型校准复现、模型/列序副本、晋级状态、内部选参摘要；最新入口见研究结论.md。
- training_integrity_audit/：冻结配置/代码/模型、列序、24入围门槛及拟合年份摘要审计，各子目录有自己的输出文件说明。
- final_report.md、training_report.md：内部验证报告及归档，没有外层收益图。
- resolved_config.yaml、research_protocol.json：退出候选、来源模型、原成本和开仓网格、研究依据与哈希。
- source_snapshot/：本轮执行源码；parent_frozen_before_test.json：原模型冻结索引，不是原外层结果。
- data_metadata.json、split_audit.csv、folds.json：复用缓存、原拟合边界和本轮内部/外层年份。
- frozen_before_test.json：本轮四折冻结规则及全部模型/表格哈希，evaluate消费。
- 年份/entry_*.json、exit_model.json：原样复制的模型；entry_feature_schema.json、exit_feature_schema.json：输入列序。
- 年份/model_feature_manifest.csv、model_metadata.json：因子中文解释、原拟合来源和本轮退出策略。
- 年份/training_rule_metrics.csv、validation_rule_metrics.csv、selection_segment_metrics.csv：校准、验证与每片段指标。
- 年份/paired_calibration_comparison.csv：同入口网格下相对原模型退出的校准差异，不是测试结果。
- 年份/selected_rules.json：各方法独立冻结规则或现金保护原因。
