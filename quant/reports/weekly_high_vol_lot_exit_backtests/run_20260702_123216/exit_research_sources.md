# 动态止盈止损资料来源

- [Investopedia Trailing Stop](https://www.investopedia.com/terms/t/trailingstop.asp)：移动止损会随着价格向有利方向移动，用于锁定利润并限制反转损失。
- [Fidelity Exit Strategies](https://www.fidelity.com/learning-center/trading-investing/trading/exit-strategies)：常见退出方式包括止损、跟踪止损、利润目标和到期重新评估。
- [StockCharts Chandelier Exit](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/chandelier-exit)：Chandelier Exit 使用最高价减去 ATR 倍数作为多头动态止损。
- [Investopedia Volatility Stops](https://www.investopedia.com/articles/trading/09/volatility-stops.asp)：波动率止损强调用 ATR 等工具把止损放在市场噪声之外。
- [Investopedia Stop Placement](https://www.investopedia.com/articles/trading/06/stopplacement.asp)：常见止损方法包括硬止损、ATR 止损、多日高低点和指标止损。
