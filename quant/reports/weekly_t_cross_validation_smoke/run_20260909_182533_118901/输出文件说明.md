# v11 输出文件

- final_report.md：启用/持有、收益、费用、失败与研究边界。
- annual_summary.csv、年度.csv、test_metrics.csv：逐年机器精度摘要。
- test_return_curve.png、测试集收益曲线.png：每年独立底仓与择时账户、净增量。
- test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv：各年原记录合并并附 test_year，不能当作连续组合。
- daily_inventory_audit.csv、blocked_orders.csv、baseline_trade_events.csv、weekly_entry_plans.csv、base_plan_mismatches.csv：实际库存、受阻和共同底仓记录。
- weekly_increment.csv：每个年度内的周净增量，不跨年续接。
- timing_reporting_status.json、goal_evaluation.json：只报告统计和约束，不触发交易；含读取输入及报告器SHA。
- validation_summary.json：原冻结规则与内部候选计数，不重新选参。
- cross_validation_results.csv 与 year_Y/ 下文件：原始入口结果，本报告器不改写。
