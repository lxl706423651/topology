# 输出文件说明

final_report.md为主报告；annual_summary.csv/test_metrics.csv为年度比较；test_equity_curve.csv、test_trade_events.csv、test_round_trips.csv、test_open_positions.csv带test_year汇总独立账户；test_return_curve.png/测试集收益曲线.png为持有及T对比图；goal_evaluation.json为统一判定。

year_*保存冻结weekly_selections.csv、实际t_predictions/t_decisions、标准成交/库存/失败/周增量CSV、execution_audit.json与frozen_baseline_audit.json。validation_rule_metrics.csv含全部27组真实执行和支持门槛；validation_candidate_audits保留候选受阻及库存失败。inner_t_h*保存所有核心训练模型、原生权重、特征、年份及来源SHA；t_model精确复制被选核心模型；support_h*.json和selected_support.json记录训练支持域；selected_rule.json以及all_rules_frozen_before_outer_test.json证明本轮先冻结规则再评价外层。

resolved_config.json、research_protocol.json、各data/recovery/horizon/provenance_manifest.json、source_hashes.json/source_snapshot和frozen_selection_sources.json记录参数、数据及源码身份。

新增oof_weekly_cohort/为本折核心标签年对应的OOF周模型、预测和队列；t_training_cohort_manifest.json为队列和模型来源。v8入口、cohort、训练域和残差源码另存source_snapshot；training_domain_h*.csv/json记录各周期训练域。

新增v8残差模型源码快照；各模型target_decomposition.csv记录有效核心标签分解及供体，model_metadata.json记录其SHA/零市场先验。validation_predictions_*及t_predictions.csv同时保存prediction、residual_prediction及恒0的market_prediction。
