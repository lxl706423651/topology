# v14第三折为何选hold：内部恢复失败只读核对

第三折指外层标签2025，以下全部是其**内部2026-01-05至04-30**的数据。36条主动规则均有完整成交，但都不能满足每日股数恢复约束，因此按原协议选择hold。没有读取外层、重跑账户、修改规则或按净收益挑诊断样本。

36条主动规则的库存差异为2–22日，恢复失败1–12日，期末pending、T+1违规、共同底仓差异均为0。仅规则34净增量为正（+1,435.44元），但它仍有6个库存差异日、3个恢复失败日；这不是净收益门槛把一条执行合格策略关掉。全部轻量库存表已逐个核对，与候选指标相符。

按照“恢复失败日数最少，再库存差异日数最少，保留全部并列”选择了规则13–18，涵盖三种退出及0.5/1.0两种份额，未使用净利润选样。六条规则均只在**SH.603949的2026-03-23**产生一次日终恢复失败：

| 事件 | 原记录 |
|---|---|
| 前一日收盘 | 2026-03-20 15:00，21.78元 |
| 当前已完成信号 | 03-23 09:45，19.68元，较前收−9.6419%，尚未达到9.8%限价代理 |
| 下一分钟首腿 | 09:46买入，参考价19.60元，较前收−10.0092%；半份额400股/全份额800股 |
| 原计划期限 | h60，10:46；三退出模式均在10:45锁存hard_deadline |
| 期限时估计含费净率 | −0.311975%，既未达到+0.3%止盈，也未达到−1%止损 |
| 每账户10:46至15:00重试 | 全165个交易分钟；145次限价代理拒绝、20次零量/零额拒绝 |
| 实际完成 | 次日03-24 09:30，以19.00元参考价卖回400/800股 |
| 此完整组净额 | 分别−264.024597元/−528.049194元 |

该日原始240根OHLCV/amount与正式dense逐值相同，六账户合990次预期重试全部存在，拒单原因按原9.8%/5%和零量优先级独立重算一致，5%分支在本例不触发。这不是遗漏分钟、提前使用未来价、现金不足、旧股不足或容量不足造成的日终失败；当前允许在跌停方向买入，随后反方向卖回受限，属于真实保留的执行风险。在这条数据路径中，把计划期限推到14:55也不会打开卖回方向；此陈述仅涉及已有路径，不是对新模型信号集合的预测。

开盘已有800股旧股，足够承接400/800股的卖回额度；实现没有把当天新买股加入当日可卖库存。首日日终多出400/800股，次日卖回使当日开收又相差400/800股，因此计2个库存差异日而只计1个日终待恢复失败日，期末pending为0。这两个计数并不矛盾。

全部36条主动规则合计涉及19个不同恢复失败股票日，3月23日这个案例影响26条，并非全36条唯一失败原因。另有SH.603103的2月10日影响30条、SZ.000036的1月20日影响24条等，见[全体发生频数](recovery_failure_prevalence.csv)。本次没有逐分钟解释其余18个股票日，也不能据此断言全部失败都由锁板导致。六个详细账户全年还有73次恢复容量拒绝，但均在其他时点完成，不是本次共同日终失败；首腿现金、旧股额度、待恢复上限等拒绝另行列在[拒单计数](minimum_sample_order_reasons.csv)。

本例支持的判断是：增加参考收益预测期限与解决同日恢复风险是两件事，当前一分钟下单延迟足以跨入反方向受限状态；固定、利润缓冲、利润加止损退出也不能保证封板时恢复。分钟OHLCV无法证明真实盘口排队必然零成交，因此这里的“受限”指冻结的保守执行规则。没有据此豁免股票、追改阈值、伪造成交或重选规则；更不构成全实现无缺陷的证明。
