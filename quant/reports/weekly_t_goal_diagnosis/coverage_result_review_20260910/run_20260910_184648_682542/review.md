# v18完整内部结果的独立表述复核

本复核仅重算已保存的小表与既存内部诊断；完整原行情、模型和账户独审由另一审计流程负责。

1. 最终内部选择是0/15/0/0：2023、2025、2026留出折的36个主动候选全部实际成交，却全部存在库存差和恢复失败，故没有执行合格候选；hold的0不是主动策略收益改善。2024折仅4个候选执行合格且均亏，选择15：378完整组、3597配对手、净−3887.12元，原始底仓成本降低率−0.4617%。

2. 频率变化并不一致：四折同数字规则的手数增加候选数为24/14/21/31（各36个），净额改善数仅17/32/1/2；对应净额变化中位数−375.45/+1996.29/−3478.22/−8779.62元。新增交易没有形成跨折稳定净增益，候选分布不能相加成一个组合。第一折4个正净额候选也均违反恢复要求，最高完整组成本降低率仅约0.5196%，不能当作达标。

3. 既存内部误差诊断仍显示成本覆盖不足：原0净边际、基准旧股机会下，8个模型/内部折的预测净差均值约+13.39至+19.48bp，而同方向固定端点标称净差均值全部为负（−42.03至−14.35bp）；标称成本覆盖率约35.55%至40.16%。这属于机会级参考端点诊断，不是实际账户成交收益，但不支持已经解决预测乐观问题。

4. 存在局部改善，应如实保留：2024折两轮均选择数字规则15，新/旧完整组378/381，单位首腿参考名义金额的毛差16.31/9.06bp，费税滑点约31.20/31.20bp，净差−14.89/−22.14bp；总净額从−5900.97改善至−3887.12元。因此不能把该处改善全部归为少交易省费，也不能由总毛额变化否定单位质量。但它仍亏损，且只覆盖这一内部样本。

5. 同数字规则对照控制了原37规则参数、费用与底仓，但新旧预测及实际成交集合不同；只强调当前内部选中的规则会保留选择乐观偏差。全37组对照可呈现异质性，仍不能替代独立样本。前三留出折内部年同为2026，最后为2025；本轮未执行正式外层，不能称2023—2026四年度验证结果，更不能把多个候选或内部折净额相加。
