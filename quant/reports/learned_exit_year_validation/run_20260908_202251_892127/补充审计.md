# 测试完成后的工程审计

本文件只解释已冻结实验的账本、模型文件和结果含义。没有重新训练、改变规则、根据测试成绩挑选其他候选，也没有重新计算测试交易。正式主报告见[final_report.md](final_report.md)。

## 后续发现：内部候选门槛覆盖

2026-09-08后续代码审查发现，共用选参器对两方法使用相同的规则字典键，方法二的门槛可能覆盖方法一。核对本轮保存的校准与验证表：2023方法一的两个入围候选门槛从约0.004219变为0.004213，2026方法一的两个从约0.002070变为0.002100；2024、2025入围候选没有数值差异。这里是收益比例，例如0.004219约为0.4219%，不是百分数4.219%。

这不是读取测试结果造成的变更，但违反了“同一候选校准后门槛不变”的约定，因此本轮不能被说成已通过全部选参合理性审计。不能未经修正重跑就断言不会影响候选排序或现金选择。上面的账本一致性与JSON重载只证明各自检查事项，不能替代此项。

保留原模型、冻结规则和交易文件，不根据外层成绩修改它们。新选参器按（方法、规则代码）分别保存，运行时检查校准/验证门槛一致，并有先复现失败再修正通过的专门回归测试。2025原交易文件相同及两方法高度重合的事实仍成立；不能把全部相同指标都归因于这个错误。

## 为什么有相同结果

2025两方法的`test_trade_events.csv`逐字段完全相同，买入重合率和日收益相关性均为1。两者选中同一开仓模型、零门槛和同一退出规则；很小的CTA叠加没有改变实际交易。这次相同指标有完整交易记录支持，不是文件误覆盖。

2024两方法买入重合率从方法一看95.04%、从方法二看99.14%，日收益相关性0.97695。方法二仍不能视为独立于方法一的风险来源。2026两者都因内部验证未通过而保持现金，相同零收益也不是漏跑。

2025同一只股票两批的待退出原因分别记录预测继续一天收益-1.5301%和-1.5415%，说明模型确实消费了不同批次状态，没有把两次买入合并成一个平均价格判断。

## 资金使用与结论

平均账户多头仓位很低：2023方法二0.59%，2024方法一/二1.58%/1.36%，2025两方法均0.25%。每笔10%是请求预算上限，不意味着实际每次都能成交到账户10%；门槛、现金、整手和分钟成交额容量均可能缩量或阻挡。不能把低仓位收益简单线性放大为满仓收益。

2026两方法的内部验证入围候选平均夏普为-1.636和-1.144，都只有1个正收益片段，因此按事前协议现金保护。2023方法一内部验证平均夏普也未通过。这些判断发生在正式测试之前。

本轮没有达到两方法各自四年平均夏普大于3。现金年度的夏普在统计上未定义；没有删除这些年度后改报均值。全部结果是包含未来训练方向、历史已见数据及不完整交易状态的回顾研究，不是实盘收益承诺。
