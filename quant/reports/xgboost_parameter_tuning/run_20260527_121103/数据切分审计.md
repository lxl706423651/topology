# 数据切分审计

- 核心训练集用于拟合候选模型：`datetime < 2024-11-01`，并且 `label_exit_datetime < 2024-11-01`。
- 内部验证集用于选择 XGBoost 参数和交易规则：`2024-11-01 <= datetime < 2025-05-01`，并且 `label_exit_datetime < 2025-05-01`。
- 最终测试集只在选中模型参数和交易规则后执行一次预测与回测：`datetime >= 2025-05-01`。
- 本调优脚本的候选排序字段为验证集 `validation_sharpe` 和 `validation_annual_return`，没有使用测试集指标参与选择。

对应行数见 `split_audit.csv`。
