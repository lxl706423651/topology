## 架构

本轮是新研究，不替换1method/2method_cta/3method的模型。复用原因子PKL，新增
主板、创业板、科创板的历史日状态及缺失特征；用XGBoost预测含T+1及退出路径的
单笔净收益，再通过CTA趋势条件、模型门槛和共享账户仓位限制下单。

严格只用过去训练。2023没有更早分钟训练数据，因此仅第四季度是启动期测试；
2024/2025为整年，2026到4月30日。不能把2023启动期称为全年测试。历史区间已
经其他研究查看，本轮是历史回顾，不是重新获得了一套从未见过的独立测试集。

## 预先固定的研究协议

- 2023：1至6月拟合、7至9月内部选参、10至12月测试；以后每年：从2023开始到
  上年9月底拟合、上年10至12月内部选参、下一年测试。训练标签必须在拟合截止前结束。
- 每折2个退出方案×2个模型；各自比较3种CTA条件×4种开仓频率×3个净收益门槛。
  所有候选和失败都落盘，不因外层收益继续扩展候选。默认每折144个内部组合。
- 用内部净日收益夏普选规则，至少5个完整平仓批次；不额外要求验证盈利才显示
  外层交易。无足够成交时按完整批次数最多、规则ID升序选择诊断方案，明确标为
  内部样本不足/未晋级；不强制开仓，也不能用现金伪装策略成功。
- 模型权重不在选参后偷偷重拟合；全量部署候选单独保存，没有独立测试成绩。
- 每个年度都独立从相同资金启动；另用连续账户跨年度切换冻结模型规则，单独
  报告真实跨年持仓曲线，不能把独立年度现金重置的拼接冒充连续交易。
- 夏普目标为连续样本外净日收益夏普>3，252日年化、无风险利率0。逐年、年度
  均值、牛熊震荡分组和置信区间都报告；观察过的历史数据不承担独立实盘验收。

## 交易约定

- 上一完整周每日分钟收益波动率均值最高的300只，至少3个有效日，每日≥120根
  合法分钟；本周固定名单。当日仅用已知状态排除ST，不使用未来存续或未来收益。
- 沪深主板、创业板、科创板；不含北交所、B股、存托凭证。不使用未来名称快照
  代替历史ST；状态缺失禁止新买入。至少60个已观察交易日历史，排除上市初期。
- 历史tradestatus（交易状态）必须为1才撮合，非正常或未知时即使分钟有成交也
  保守拒绝两侧订单。原始矛盾记录不改写，退市整理等特殊状态仍须完整授权数据核对。
- 信号在完成分钟生成，下一交易分钟收盘加滑点模拟成交；午休不计时，不在集合
  竞价或盘后交易。风险每分钟检查，禁止同bar决定后同bar成交。
- 主板普通股10%、科创板/创业板20%日涨跌幅限制，以历史参考价四舍五入到分计算。
  涨跌停价均不撮合买卖；分钟内曾触板不代表其他正常价格必然不能成交。
- 主板/创业板买入100股整数倍；科创板最低200股、之后1股递增。科创板不足
  200股余额一次性卖出；成交量约束是撮合代理，不等于盘口排队或券商保证成交。
- 每次最多5只，各笔预算为总资产10%，同股次日可独立加仓；单股累计20%、总仓80%。
  不做空、不融资；换池不平仓，每一批次单独止损、跟踪止盈、趋势退出及到期退出。
- 初始止损=成交价−入场ATR×倍数；跟踪线=历史保护线与持仓后高点−ATR×倍数
  的较大值。ATR使用上一已完成日的14日平均真实波幅。趋势退出为价格跌破上一
  已完成日EMA20；到期按交易日计数。T+1、停牌/涨跌停会延后退出，止损不保价。
- 双边万八佣金、免5、双边过户费十万分之一、卖出按日期适用印花税、双边万五
  滑点，每分钟最多参与成交额5%。资金不足取消新买单，不创建负现金。

## 历史数据输入

`history_data_dir`默认null，使用已下载缓存；指定本地授权目录后只读该目录，
不发网络请求。每股文件名为`SH.600000.pkl`、`SZ.300001.csv`等，基准为`SH.000300`。
必须包含`date（交易日期）`、`open/high/low/close（未复权开高低收）`、
`preclose（当日价格限制参考前收盘）`、`volume（股）`、`amount（元）`、
`tradestatus（正常交易1、停牌0）`、`isST（当日风险警示状态1/0，未知留空）`。
参考价需要涵盖除权特殊处理；本轮未完整实现分红送转和税务现金流，仍不能实盘验收。

日期必须唯一，历史应覆盖2022年9月至2026年4月，首次上市股票从真实上市日开始。
当日isST必须是该日生效且盘前已可知的历史状态，不是下载日快照。缺失不会填成0；
信号不使用当日日终收盘/成交量生成盘中交易资格，日尺度特征统一滞后一日。

不得自动清除`provider_access_denied.json`或更换身份绕过限制。数据商恢复授权后
由用户指定可用数据源；已有下载文件及失败过程全部保留，不删除原始数据。
