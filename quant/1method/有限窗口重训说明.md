# 有限窗口与原始来源隔离重训

## 架构

原年度274因子及行情pkl（只读复用） -> 232个有限窗口白名单 -> 单股真实分钟观测来源与简单ATR支持pkl -> 完整原截面来源传播 -> 20交易日以内环境特征与3/5日标签 -> 每折核心拟合/校准/验证 -> 四折模型和策略冻结 -> 满足条件后单独外层评价。

本轮不是继续复用旧模型调退出：开仓和持仓模型全部重新拟合。原EMA（指数均线）、RSI（相对强弱）、Wilder ATR（递推平均真实波幅）、ADX（平均趋向强度）、MACD（指数均线动量）、累计OBV（能量潮）及使用全局序号的趋势列共42列不进入新输入。232个白名单是候选因子，模型最终最多154列，仅由各折核心拟合片段筛选；不能把白名单数量当最终特征数。

数据和撮合中ATR也改为最近240个有效分钟真实波幅的简单均值，额外读取一条前收，因此最早来源为当前及此前240条原始观测。它不是旧Wilder ATR的同义实现，也不保证效果更好。[TA-Lib官方ATR源码](https://github.com/TA-Lib/ta-lib/blob/main/src/ta_func/ta_ATR.c)中的递推状态是本次检查依据；不能因为隔离了固定日数就宣称稀疏行情已完全遗忘旧年份。

本轮全量缓存和20模型重训已完成，见[中文研究结论](../reports/bounded_year_validation/run_20260908_222819_626855/研究结论.md)。方法一仅2023/2024折内部通过，方法二仅2023折通过，未满足事前外层晋级条件；未进行正式外层测试，目标未实现。64项测试、20模型/24候选冻结审计与逐行拟合来源重建通过，仅是工程证据。小样本只验证代码路径，不能作为夏普目标证据。

## 如何隔离数据

1. 限定旧分钟因子为明确有限窗口，最大241条原始观测。剔除全局序号趋势是保守数值处理，不声称普通滚动趋势数学上无限依赖价格。
2. 支持缓存记录每个时刻本股的原始窗口最早日期和真实前收来源；长期停牌不能把前收来源猜成前一个交易日。
3. 原因子截面秩在旧完整入池截面上计算，所以来源也在交易资格过滤前传播：任一贡献者有旧年份来源，整个该时刻的秩都按更早来源核对。未知来源失败关闭，不静默当安全。
4. 新增环境/截面特征最长20交易日，删除原60日动量和60日回撤两列。这样核心拟合不借用上年验证价格时，2026年仅77个交易日的数据仍可提供部分训练样本；不是用验证或测试收益挑窗口。
5. 外层继续排除留出年及其后的60个共同交易日，并额外剔除来源包络触及留出年的行；短窗口没有放宽这项隔离。
6. 核心拟合及其虚拟持仓入口另要求来源不早于该年1月1日，避免下一年训练读取上一年内部验证价格。校准/验证本身可像实时预测一样读取此前正常历史；标签终点仍必须在本内部窗口内。
7. 虚拟入口按“时间、股票”的固定哈希键约八取一。删除其他年份的入口不会改变本年份抽样；不再用全表iloc（按行位置）每隔8行抽样。
8. 校准分位门槛及选中规则在内部验证前确定，验证后不重拟合，四折统一冻结再考虑外层。

这仍是用户接受的留一年回顾协议。2023/2024折可使用2026核心拟合；2025折保留60日外层隔离后，2026核心前60%可能没有可用行，但后段仍可内部选参。2026折本身不能用2026训练。实际年份和行数以split_audit.csv为准，不能一概说前三折都有未来核心拟合。

## 交易规则

开仓模型预测3或5个交易日同刻下一分钟买卖的成本后净收益。方法一按该分数排序；方法二共用同一XGBoost核心和原小权重CTA叠加公式，但只用仍存在的有限因子，整组缺失时为中性0.5，因此不是旧CTA数值的复现，更不是独立收益来源。

上一周高波动前300主板股票池，每24分钟最多前5且通过校准门槛，基础净收益预测必须非负。每笔买入最多信号时总资产10%，同股隔日新增独立批次；总仓位不加杠杆，离开前5或股票池不构成平仓条件。

本轮沿用原多尺度的4种退出网格，不按上一轮外层结果挑选：最早T+1时间对照（ATR30/60倍）、继续持仓模型零门槛（ATR20/40倍）、继续持仓模型负0.10%门槛（ATR20/40倍）、零门槛（ATR30/60倍）。模型退出另有20交易日保护。每批成本/年龄/最高价独立；ATR保护可提前触发，但T+1、缺行情、价格代理及容量限制可能延迟或部分成交。

费用、资金和撮合不变：佣金双边万八且免5，双边过户费十万分之一，历史分段卖出印花税，单边万五滑点，严格下一分钟成交、100股整手、最多该分钟成交额5%。

## 阶段与命令

在quant根目录使用quant Python。首次全量build-only需要读取原始分钟行情，但只额外构建来源/简单ATR支持，不重建274因子；以后同指纹直接加载pkl。

~~~bash
# 语法及人工数据测试
python3 -m py_compile quant_backtest/bounded_training.py scripts/run_bounded_year_validation.py scripts/run_multiscale_year_validation.py tests/test_bounded_training.py
/home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -v

# 八股票数据和流程检查，重复build-only应加载相同pkl
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_bounded_year_validation.py --smoke --workers 2 --build-only
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_bounded_year_validation.py --smoke --workers 2

# 全量数据审计，随后重训全部20模型并内部选择，默认不预测外层
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_bounded_year_validation.py --build-only
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_bounded_year_validation.py --phase train

# 核对本轮冻结代码、模型、列序及所有入围门槛
# 此命令同时重建每个模型的拟合行和来源
/home/lxl/anaconda3/envs/quant/bin/python scripts/audit_bounded_training.py --run-dir reports/bounded_year_validation/run_时间戳

# 只有满足下述事前晋级条件才执行；不是train之后无条件自动调用
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_bounded_year_validation.py --phase evaluate --run-dir reports/bounded_year_validation/run_时间戳
~~~

正式外层晋级条件在本轮全量训练前确定：**至少一种方法全部四折内部启用**，否则不安排正式外层评价，也不画假的测试曲线。此条件只是人工流程必要条件，CLI不会自动执行测试，满足也不保证达到平均夏普3。烟测可以评价以验证报表路径，但必须标明无盈利意义。

内部筛选仍为每方法每折4模型×3分位×4退出＝48候选；校准至少20完整平仓才可入围，前3送验证。验证要求平均夏普为正、至少20完整平仓、至少2个正收益片段。全部失败则现金保护，不能删现金年算平均。最终目标仍是完整四折实际净收益夏普均值严格大于3。

## 配置字段

| 字段 | 必需/默认 | 消费者及作用 |
|---|---|---|
| base_config | 必需，提供config/multiscale_year_validation.yaml | 分层加载器继承数据、成本、仓位、日期、模型和门控 |
| output_dir | 必需，提供reports/bounded_year_validation | 新入口写独立数据审计与实验目录，烟测加_smoke |
| bounded_cache_dir | 必需，提供reports/bounded_year_validation/cache | 有界数据组件存新支持/面板/持仓缓存，烟测加_smoke |
| data_contract | 内部生成bounded_observation_v1，非新增用户参数 | 阻止新配置误走旧数据入口，写入resolved_config.yaml |
| atr_definition / candidate_basis | 内部生成中文定义，非用户调参项 | 报告、持仓列说明和研究协议保存语义，不改变费用 |
| --workers | 可选，默认继承12 | 只覆盖线程/进程数并记录，不改变收益参数 |
| --smoke / --build-only / --phase / --run-dir | 可选CLI，默认正式train | 分别控制小样本、只构建审计、阶段及冻结输入目录 |

其他继承字段详见多尺度及双模型说明。没有新环境变量。源码或输入指纹改变会进入新缓存目录；旧缓存不删。共用组织器新增有界注入及来源筛选，因此旧实验在当前源码上重新审计可能报哈希变化，属于保护行为；复现旧实验须用其source_snapshot（源码快照），不得修改旧冻结文件绕过校验。

继承配置中的aux_cache_dir、multiscale_cache_dir属于旧数据入口，本轮有界入口不从这两处读取旧持仓或多尺度pkl；新支持、面板和持仓文件均由bounded_cache_dir管理。signal_cache_dir仍用于复用当前分钟交易资格。--config可选，默认config/bounded_year_validation.yaml。

## 输出与限制

正式train生成final_report.md（内部主报告）、training_report.md（原内部归档）、输出文件说明.md、resolved_config.yaml、research_protocol.json、源码快照、split_audit.csv、folds.json、frozen_before_test.json，各年份模型JSON、中文特征清单、selected_rules.json、feature_source_audit.csv和校准/验证/片段指标表。

feature_source_audit.csv（外层排除后可供内部研究的来源摘要）包含校准、验证候选，**不是实际核心拟合行**。其中signal_year为信号年份，rows为入口行数，first_source为最早量价来源，first_signal/last_signal为首末信号。实际核心拟合还检查fit_source_allowed（来源在本年），须对照split_audit.csv以及bounded_source_audit/中的真实拟合来源核对.csv，不能用可用候选的跨年来源误判已进入核心训练。

只有正式evaluate实际执行后，才按原标准生成8组年度测试曲线、图上指标、逐笔买卖触发原因、平仓与未平仓记录、日终持仓、费用及执行审计。没有测试时不冒充已有测试结果，不覆盖旧报告。

本轮只针对已明确的量价来源路径及抽样依赖进行修正。非历史ST名称快照、复权/公司行动、观测日历和撮合代理偏差仍在；有限窗口的前缀扰动测试带浮点容差，不是对全量全部特征作逐值重算。历史数据反复研究及未来年份训练也意味着本实验不能作为未见未来数据的实盘业绩。
