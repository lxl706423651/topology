# 多尺度开仓与独立退出研究

## 架构

这是继双模型留一年实验后的新研究版本。设计依据是旧开仓模型的一日目标与较长持仓保护期限可能不匹配，以及动量、波动、流动性特征需要较长历史尺度；不是根据已看到的年度测试收益挑参数。

已有274因子面板/连续行情/持仓状态pkl -> 当前交易资格 -> 多尺度特征与3/5日标签pkl -> 每折拟合 -> 校准候选 -> 内部验证 -> 四折冻结 -> 外层测试。

仍采用2023、2024、2025、2026各留出一次，2026只含现有1至4月。前三折使用未来年份的信息，仅能回顾解释，不能说模型在当年真的可得。外层测试年的样本行不进入本折拟合和选参；内部每个训练年前60%交易日拟合、中20%校准、末20%验证，段首隔离7自然日。多日标签的结束时刻也必须严格在拟合段内。

另外，留出年之后的前60个实际共同交易日不进入任何内部阶段，第一条允许的信号在第61个交易日；新增60日动量的起点因此不落在留出年。这只筛学习和选参行，连续行情与特征pkl照常复用，外层推断也不按未来标签完整性删行。原有分钟递推指标及历史股票状态仍有下文所列限制，不能把这项边界检查扩大解释为全数据严格独立的证明。

2026仍可用于2023、2024折的核心拟合。2025留出折隔离后，2026前60%拟合段没有剩余行，但后面的校准/验证仍可能使用2026；不能为了强行加进2026而缩短隔离。`future_trained`（核心模型是否拟合未来年份）依据实际拟合行计算，`future_selection`（是否安排未来年份校准/验证）单独记录，后者为真也不能称为向前测试。

目标仍为两方法各自完整四年平均夏普大于3；不存在任何一版实现就默认本版实现的借用关系。无波动年不剔除，不能用内部验证成绩冒充外层测试。

## 阶段调用

在quant根目录执行。命令不改原始行情、不连接券商、不推送Git；训练会写新模型和新增特征缓存。

```bash
# 语法和合成约束检查
python3 -m py_compile quant_backtest/multiscale_training.py scripts/run_multiscale_year_validation.py
/home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -v

# 8只股票的小规模内部训练
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_multiscale_year_validation.py --smoke --workers 2

# 全量内部拟合、校准、验证与四折冻结，不生成外层测试预测
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_multiscale_year_validation.py --phase train

# 冻结后审计门槛/模型/年度摘要，输出新的training_integrity_audit子目录
/home/lxl/anaconda3/envs/quant/bin/python scripts/audit_multiscale_frozen_training.py --run-dir reports/multiscale_year_validation/run_时间戳

# 只对上述已冻结的新目录进行一次外层测试
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_multiscale_year_validation.py --phase evaluate --run-dir reports/multiscale_year_validation/run_时间戳
```

最后一步先校验配置、代码、模型和缓存指纹。已经出现test_started.json的目录不能再次测试或覆盖。训练阶段的final_report.md只包含内部验证，不生成假的测试图；评价后才生成各年度收益曲线、交易/平仓/未平仓和标准文件说明。

在冻结后可另做只读训练内部诊断：`python scripts/audit_multiscale_training_execution.py --run-dir reports/multiscale_year_validation/run_时间戳`。它读取模型与内部窗口，在新`training_execution_audit/run_*/`写诊断表/说明，不打开任何外层测试预测或收益。其“容量加权标签代理”不是组合收益，下一分钟是否可成交只用于标签诊断，不能加入实时特征。

## 特征与目标

- 原分钟因子保留，新增过去1、3、5、10、20、60个交易日同刻收益；过去5/20日采样收益波动率；距过去5/20/60日采样最高收盘的回撤；当前相对前收盘收益、量比、成交额。新增个股状态在当时合资格周度池内求百分位秩。
- 加入5个非排名环境量：当期周池平均日收益、上涨比例、5日平均动量、日收益截面分散度和盘中时间。它们只统计当时可见、合资格的周池，不能使用未来入池股票。
- 每折最多154列，先保留在拟合片段有覆盖及变化的环境变量，其余名额在截面因子中按拟合相关性/覆盖率/冗余筛选。共享特征筛选只用5日标签且剔除跨界标签；3日与5日模型各自用自己的合法标签拟合。
- 开仓目标是下一分钟买入、3或5个交易日后同刻下一分钟卖出的成本后净收益。佣金、税、过户和双边滑点照旧，标签截断正负20%以控制训练极端值，但不截断实际回测亏损。模型输出基点，除10000才是收益比例。
- 新标签缺失不能删掉尾部可预测行情。未来标签虽然存于同一可信本机pkl，但特征清单和预测输入绝不包含future_return或future_end列。
- 持仓模型仍预测继续一天相对立即卖出的净所得增益，沿用原15个行情/独立批次状态。只从旧虚拟样本中筛出“历史入场时符合新交易资格”的批次，不要求该股票目前仍在池。

共同时钟一天10个信号点加1个日终点，11点对应下一交易日同刻，不是11分钟。多日标签按实际共同交易日历映射，不按自然日或股票缺失后的下一行代替。

## 开仓和平仓

仍使用上一自然周高波动前300，非ST/退市筛选局限与原实验一致。本版额外要求信号分钟非一字线、当时成交额至少20万元；不提前看下一分钟能否成交，也不放松原来的涨跌停代理与5%成交额容量限制。

方法一按净收益预测排序，方法二加少量CTA趋势分。基础预测净收益为负，两方法都不能买；每时点最多前5且逐只超过训练校准门槛，每笔成交额最多当时总资产10%。现金不足或容量不足会缩量。隔日同票可以增加独立批次，单票累计仓位不保证低于10%；不能做空或加杠杆。

比较四种退出候选：

1. 首个满足T+1的采样时点退出作为时间对照；模型退出阈值设为极低哨兵值以关闭模型触发，ATR30/60倍仍作紧急保护。此项不是24小时后固定卖，也不保证次日成交。
2. 继续一天预测收益不高于0则退出，ATR20/40倍保护，最长20交易日。
3. 继续一天预测收益不高于-0.10%则退出，ATR20/40倍保护，最长20交易日。
4. 继续一天预测收益不高于0则退出，ATR30/60倍保护，最长20交易日。

ATR仍是240根原始分钟线的平均真实波幅，不是日线ATR。每批次单独管理买价、费用、浮盈、持仓日龄及保护线。离开选股池不构成平仓条件。退出意图下一分钟尝试成交，T+1、缺失价格、跌停代理和容量不足可能延迟或部分卖出。

## 研究限制

多日净收益开仓目标不等于最终必然持有3或5日，退出模型可能更早发意图。这种目标与动态退出之间仍存在分布差异，必须以真实组合回测验收，不能仅凭预测误差证明盈利。

成本仍为双边佣金万八免5、过户十万分之一、日期对应卖出印花税、双边万五滑点；按下一分钟价格成交、T+1、100股整手、分钟成交额5%容量。原始复权、历史ST/退市、盘口排队和陈旧估值问题没有因增加特征而消失。

60交易日隔离针对新增的有界长窗口。复用的分钟因子还包含EMA（指数移动均线）、RSI（相对强弱指标）等递推状态，尤其长期缺行情股票不能仅凭共同日历断言其递推记忆完全清除；本轮没有重算按外层边界重置的全部分钟因子。这与名称快照等限制一起阻止本报告被当作严格点时、完全独立的实盘业绩证明。

最新外层结果：2023方法一/二收益-3.74%/-4.69%、夏普-0.701/-0.891；2024方法一收益-41.00%、夏普-1.624、最大回撤48.48%，方法二现金；2025两方法现金；2026年1至4月方法一/二收益3.38%/3.34%、夏普0.832/0.835。两方法均有无波动年度，完整四折平均夏普未定义，不能删除这些年度。该版本不作为实盘候选，也不据这些外层结果回选其他规则。
