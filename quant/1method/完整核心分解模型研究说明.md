# 完整核心加权与环境分解模型

## 架构

目标仍是具有独立开平仓规则、完整四年回顾平均夏普严格大于3的A股仅做多策略。
本轮研究训练样本利用率和监督结构，不改变上一自然周高波动300、前5门控、每次总资产10%、T+1、费用或退出。
旧XGBoost、CTA、路径模型及其成绩不替换。研究结论须以新目录冻结后的实际结果为准，不预先宣称达标。

数据链路：既有有界特征pkl和执行路径标签pkl -> 逐折完整核心窗口 -> 同股标签并发降权、日期等权
-> 直接净收益或环境/个股双分量训练 -> 内部校准、短名单验证 -> 冻结及真实输入重建审计
-> 四折晋级后唯一一次年度留出回顾 -> 中文曲线、逐笔交易和参数报告。

## 研究依据

只在2026留出折的2023至2025核心训练中检查：3/5/10日完整标签61,230/60,213/57,819条，
原股票相位抽样后仅6,869/5,493/3,605条。各有345/339/324个核心日期，同刻预定入口数中位数17。
同刻共同收益方差占原标签方差约14.33%/13.32%/12.86%，不是主要解释，更不能据此断言市场择时有效。
这些检查没有读取外层策略收益，用于制定完整样本对照和监督分解假设。

[Qlib截面处理源码](https://github.com/microsoft/qlib/blob/main/qlib/data/dataset/processor.py)提供截面归一化思路；
[标签并发/唯一性文档](https://mlfinpy.readthedocs.io/en/latest/Sampling.html)说明重叠观测的依赖；
[LightGBM 4.6.0接口](https://lightgbm.readthedocs.io/en/v4.6.0/pythonapi/lightgbm.LGBMRegressor.html)支持训练样本权重。
本实现使用净收益均值分解而不是直接复制Qlib秩标签，也不复制收益幅度加权或序贯随机抽样；这些资料不证明A股盈利。

## 本轮结果

[正式内部研究结论](../reports/pooled_path_year_validation/run_20260909_095128_476739/研究结论.md)：48包/72分量完成、144校准/23验证/501内部片段，87项测试及实际输入/权重/分量重载通过。
直接模型只通过2023/2026内部折，分解模型通过前三折而2026失败；两类固定模型族均未晋级，正式外层未运行，没有本轮测试曲线，平均夏普3目标未达。

## 标签和权重

沿用一股一天按股票/日期哈希预定一个钟的路径标签，未成交收益0，期限加5交易日仍未卖完则按市值记录。
完整潜在窗口必须落在核心片段，提前平仓不放宽。仍排除留出年、之后60交易日及实际量价来源触及留出年的行；
核心来源不能借用上年内部验证行情。内部核心/校准/验证仍为各非留出年60%/20%/20%，保留7自然日起点隔离。

本轮不再每H+6日只取一个训练入口，允许**同一核心片段内部**标签重叠，跨角色边界不允许。
每股每年在固定潜在闭区间上计算每个共同钟点被多少标签覆盖；每个入口的唯一性为窗口内1/并发数均值。
将该唯一性除以当天唯一性总和，再归一至全体样本平均权重1，因此每天总权重相同。
权重不看收益大小、好坏或提前退出时间。它只能降低重复权重，不能消除相关性或证明独立样本量增加。
完整同刻标签少于5的核心组不拟合，两方法使用同样样本；推断不按未来标签是否存在筛选股票。

## 模型和推断

账户净收益标签截断为正负2%，训练以基点为单位，推断除10000。
方法一用固定29个当时输入直接拟合净收益。方法二先在核心同一时点计算加权平均标签m，再拟合：

- 环境分量：5个当时环境量 -> m（同刻共同净收益）。每个时点仅一条环境训练行，日期权重仍相同。
- 个股分量：24个当时个股量 -> y-m（相对净收益）。去掉5个环境输入，保留有限因子及当时量价。
- 推断：预测账户净收益 = 冻结环境预测 + 冻结个股预测；不读取当前/未来的真实收益或重新拟合分量。

同刻环境量必须一致，部分缺失与有值混杂会拒绝训练。环境可以整体缺失，由LightGBM在核心学习缺失方向。
推断不强制当前截面残差重新归零，每行独立相加，支持分批结果一致。
该m来自核心预定入口的样本，不是可交易指数；没有空头，也不凭空获得市场对冲收益。
相对收益大于0不等于股票绝对盈利，最终门槛在合成净收益分数上按内部校准定义。

## 交易与验收

每24交易分钟选最高5只且通过门槛才尝试买，每笔最多信号时总资产10%，同股同日最多一次，隔日可独立加仓。
离池不卖，初始20倍/吊顶40倍简单分钟ATR或模型3/5/10交易日同刻到期触发退出，T+1后下一分钟尝试执行。
万八免5、历史印花税、过户费、万五滑点、5%分钟成交额共享容量、100股和涨跌停代理不变。
退出待单和部分成交保留，期末不虚构强平。详见[执行路径说明](执行路径模型研究说明.md)。

每折12模型包（6直接、6分解），共48包、72个LightGBM分量。3个门槛分位对应144校准候选，最多24个去重模型候选验证。
同一折同一期限的两个复杂度候选使用相同环境模型参数和训练行，环境预测等价；72个保存分量不等于72个独立策略或收益来源。
内部须全部3片段有波动、均夏普>0、至少20完全平仓批次、至少2正收益片段，失败则现金保护。
至少一种方法全部4折内部启用且审计通过才正式外层；同一方法4个有效年度夏普均值严格>3才达标。
现金或亏损年不得删除，两方法不能逐年择优拼接，烟测或内部夏普不能当测试成绩。

## 调用顺序

在quant根目录使用以下命令。首次新增训练会写新模型和报告，原因子与路径pkl复用。

    /home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -q
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --smoke --workers 2
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --phase audit --run-dir 实际烟测目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --phase evaluate --run-dir 实际烟测目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --workers 4
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --phase audit --run-dir 实际正式目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pooled_path_year_validation.py --phase evaluate --run-dir 实际正式目录

新入口没有build-only；检查标签缓存可调用旧路径入口的build-only，具体命令见执行路径说明。
正式未晋级时不执行最后一步，不创建虚构测试曲线。audit逐项重建实际输入及分解监督，核对每个原生txt的预测。

## 新配置字段

| 字段 | 必需/默认 | 消费者和作用 |
|---|---|---|
| base_config | 必需，config/pathwise_year_validation.yaml | 新入口，继承路径/交易/隔离约束 |
| output_dir | 必需，reports/pooled_path_year_validation | 新入口，独立报告目录 |
| pooled_min_label_group | 必需，5；烟测1 | select_pooled_training，核心同刻标签数下限，不是推断未来过滤 |
| pooled_model_profiles | 必需，两组 | create_pooled_profiles；name名称、num_leaves叶数、max_depth深度、min_child_samples叶样本、n_estimators树数、reg_lambda惩罚 |
| pooled_environment_model | 必需，3叶/2层/40叶样本/100树/L2=25 | fit_pooled_model固定环境模型，不另增选参网格 |

其余固定基准learning_rate=0.03、reg_alpha=1、行列全采样、确定性CPU、种子与线程继承；YAML参数可显式覆盖，实际值保存在resolved_config。
path_horizons、ATR、费用、label_clip、gate_quantiles、simple_shortlist及交易数门槛继续有效。
path_model_profiles、ridge_penalties、isotonic_families及旧XGB候选不用；path_training_phase仅供90个核心路径参照抽样，实际拟合不用它。

## 风险

前三折允许未来年份训练或选参，只是用户接受的回顾研究，不是当年的真实可部署表现。
2026仅1至4月，实际是否参与核心见split_audit.csv；2025折可能仅有2026后段内部选择而无2026核心拟合。
当前ST快照、幸存者、公司行动和复权、采样止损与撮合代理仍限制实盘可用性。历史已经多次研究，不能称为全新未见测试。
