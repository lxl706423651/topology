# 双方法年度滚动验证与2026数据重训

## 架构

本流程分开保存“历史年度验证模型”和“全量部署候选模型”。前者检查不同年份的稳定性，后者包含2026年数据，但没有独立未来测试成绩。

方法一使用XGBoost（梯度提升树）预测同一股票池内的收益排序。方法二在同一个模型分数上增加CTA（趋势跟随风格）技术因子叠加，不是独立训练的另一种预测模型。两者各自选择门控与退出规则，使用同样的数据、执行引擎和资金约束。

原始分钟行情 -> 上一周高波动股票池 -> 共同时钟特征pkl -> 每轮训练期筛特征/拟合 -> 训练内部校准 -> 验证选规则 -> 冻结 -> 年度测试。

另一路：2023至2026年4月的全部已完成标签 -> 重新筛特征和拟合 -> `deployment_candidate`（部署候选），等待未来验收。

| 测试轮 | 核心拟合 | 训练内部校准/退出初筛 | 独立验证/规则确认 | 测试 |
|---|---|---|---|---|
| 2024 | 2023年1至6月 | 2023年7至9月 | 2023年10至12月 | 2024全年 |
| 2025 | 2023年1月至2024年6月 | 2024年7至9月 | 2024年10至12月 | 2025全年 |
| 2026 | 2023年1月至2025年6月 | 2025年7至9月 | 2025年10至12月 | 2026年1至4月 |
| 最终全量候选 | 2023至2026年4月全部已完成标签 | 不按测试成绩调参 | 沿用2026轮的测试前验证规则 | 无独立未来测试 |

每个区间左闭右开，训练标签结束时刻也必须严格早于训练截止。最后一天没有下一交易日标签，不用于拟合。2023年缺乏更早训练数据，不能用2024—2026训练再倒测2023并称为真实样本外。

一个年份在早期轮做测试、在后续轮进入历史训练，符合时间向前；但不能用2026训练出的模型回测2024并声称无前视。所有年度规则在查看本轮年度测试结果前冻结。已经被此前研究查看的历史数据，重新切分不能恢复为完全未见数据。

## 文件角色

| 文件/目录 | 角色及职责 |
|---|---|
| `config/annual_method_validation.yaml` | 用户输入：日期、股票池、成本、模型、退出候选与目录 |
| `scripts/run_annual_method_validation.py` | 可执行入口：组织训练/验证/测试、冻结规则、保存模型与中文报告 |
| `quant_backtest/annual_panel.py` | 帮助库：行情检查、统一时钟、股票池与可复用pkl |
| `quant_backtest/factor_library.py` | 既有274因子的具体计算实现，只使用已完成历史分钟线 |
| `quant_backtest/annual_training.py` | 帮助库：年度分割、跨界标签清理、特征选择、中文因子解释、拟合 |
| `quant_backtest/annual_portfolio.py` | 帮助库：独立批次、现金、费用、T+1、成交延迟、容量、止损、日频指标 |
| `scripts/run_multi_factor_cta_backtests.py` | 既有CTA打分帮助函数，方法二叠加定义 |
| `scripts/run_dynamic_high_vol_method_backtests.py` | 既有日内波动率/上一周高波动选股帮助函数 |
| `tests/test_annual_validation.py` | 合成行情单元测试，无实盘或数据修改 |
| `scripts/audit_annual_training_gates.py` | 只读训练内部校准/验证行情的门控审计入口，排查涨停/零量/容量阻挡，不读取测试预测 |
| `reports/annual_method_validation/panel_cache/` | 大型生成缓存：日波动率、单股文件、合并特征、行情与质量审计，不入Git |
| `reports/annual_method_validation/run_*/` | 生成报告：总说明、年度指标、冻结记录、模型/规则与交易记录 |
| `reports/annual_method_validation_smoke/` | 小规模流程测试输出，不能用来评价策略，不入Git |

各次运行根目录及各方法子目录均含`输出文件说明.md`。模型和英文特征列的含义可查`model_metadata.json`与`feature_selection.csv`的中文说明列。

## 交易与计算口径

- 时间戳为上海本地交易时间，以无时区格式存储。午休不算交易分钟。
- 候选取沪深主板所有年份文件的并集，不要求2025/2026同时存在。排除科创板、创业板、北交所；ST/退市名称按2026固定快照排除，历史点时状态仍缺失。
- 每周只用上一自然周数据，至少3个有效交易日，按平均日内分钟收益标准差取前300，成交额用于同分排序。上一周不足3天时不新买，已有持仓继续管理。
- 信号统一为09:31、09:55、10:19、10:43、11:07、13:01、13:25、13:49、14:13、14:37；15:00另作估值和退出检查。缺失分钟不会改变某股票的采样相位。
- 固定274因子转为当时股票池内的百分位秩，按当轮训练覆盖率、与目标相关性和特征冗余选最多154列，不保证恰好154列。XGBoost保留缺失值；特征筛选相关矩阵中的缺失按0.5中性值填充。
- 在模型拟合、门控校准和前5排序前，使用信号时已经可见的价格/前收盘/成交量/成交额筛可买候选；剔除当时的涨停代理、零量和连一手预算都不满足的股票。筛选不读取下一分钟成交数据，股票池截面因子仍参照当时原始周度池，标签秩在可买候选内重算。
- 目标是下一分钟收盘到下一交易日同一分钟收盘的收益截面秩，更贴近T+1。未来标签不进入特征和回测信号表。
- 每点最多前5且逐一过门控，门控来自训练内部校准期最高分的分位数。退出候选训练内初筛、验证确认；验证没有正夏普且足够完全平仓批次时，按事前规则保持现金。
- 每笔预算不超过信号时已知总资产10%，不是可用现金10%；受现金、100股整手和成交额约束向下缩减。下一交易日可对同票增加独立批次。单票累计仓位可能超过10%，但不加杠杆。
- 每批次初始止损为买入价减入场ATR240倍数；移动止损为持仓最高价减当前ATR240倍数，与旧止损取最大值，不能放松。入场后首个监控区间保守只用当前收盘更新最高价，后续区间用全部中间分钟最高价。
- 开仓/平仓都在信号的下一分钟收盘加不利滑点模拟成交。日终退出延续到下一交易日首个采样点，再尝试下一分钟成交。掉出股票池/前5不构成平仓原因。
- T+1、缺失、零量、保守涨跌停代理和容量限制可能延迟/部分平仓。失去新行情的持仓使用最后已知估值，不估为0；股票池变化不影响继续估值和止损。
- 各年独立从100万元现金开始，年末不虚构强平。夏普以每日收盘权益收益、含空仓日、252交易日、无风险收益0计算；年化收益按自然日复合；首日成本纳入收益/回撤。
- 手数包括买卖双边；换手为双边成交额/平均日终权益；胜率按完全平仓批次聚合，未完成批次另列。

## 结果与限制

先看`annual_test_metrics.csv`逐年收益/夏普/回撤，再看`cross_year_summary.csv`平均与最差年度，不挑最好一年。每个`year_YYYY/method1`或`method2`都包含中文测试收益图、指标、逐笔交易与期末持仓。

若某年空仓，查看该年的训练/验证候选表及`selected_rules.json`，确认是否验证未达标触发事前现金保护。方法曲线相同时应查看`method_overlap.csv`，相同预测核心可能产生相同订单。

本地缺少完整历史ST/退市和复权信息。涨跌停仅为保守代理，不是实际限价/竞价/排队模型；容量和固定滑点也不能替代冲击模型。年度切分并不保证覆盖完整牛熊周期。不能单凭高夏普决定实盘。

第一版报告`run_20260908_135753`保留为门控问题的诊断记录：各轮触发现金保护。其训练内部校准期高分候选大量在涨停代理范围内，因此第二版把信号时可买过滤提前到训练与校准入口。修正依据训练/验证审计，不是根据年度测试表现选择参数。现金且无波动时，CSV夏普0为占位值，统计上的夏普并未定义。

最终全量模型重新拟合后分数分布可能变化，继承的门控须在未来模拟盘验收。不能用年度模型的成绩替代它的独立成绩。

参考：[scikit-learn时间序列切分](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)；[税务部门印花税公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)。
