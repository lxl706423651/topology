# 预测期限与退出对照研究

## 架构

本研究检验一个事先提出的假设：开仓模型的3/5交易日收益目标，是否与原来逐时预测继续一天的退出方式不匹配。这个假设尚未证实，不能把上一轮外层亏损归因于过早退出，也不能据外层交易挑新参数。

本轮[正式内部研究结论](../reports/exit_alignment_year_validation/run_20260908_215813_680118/研究结论.md)已完成：方法一只在2折内部启用、方法二只在3折内部启用，均有现金保护年份，未满足外层晋级条件。没有运行本轮正式测试，也没有本轮正式测试收益图；目标未达到。576个校准候选和24个验证候选共完成1800次片段回测，20个模型与来源相同、192组原退出校准对照精确复现、55项回归测试通过。

冻结的全部开仓/持仓模型 -> 原特征pkl与原内部窗口 -> 相同拟议开仓分数/门槛 -> 六种退出对照 -> 校准前3入围 -> 内部验证 -> 四折统一冻结 -> 单独外层回顾评价。

不重新拟合、重新挑因子或复制来源测试预测。本轮继续使用2023至2026留一年协议；2026数据进入其他折的情况与原模型完全相同。前三折包含未来年份拟合或选参，仍不是当年可取得模型的向前实盘检验。全部旧数据偏差和递推因子状态限制也保留，不能仅凭换退出规则消除。

## 交易规则

开仓不变：上一周高波动前300主板股票池，当前非一字线且分钟成交额至少20万元，基础预测非负，每时点最多前5且过校准门槛。每笔买入成交额最多信号时总资产10%，不是剩余现金的10%；资金/容量不足缩量。同股隔日加仓形成独立批次，单票累计仓位可超过10%，总仓位不能超过现金账户允许范围。

六种退出对照均使用同一ATR初始20倍/移动40倍保护，ATR为原240分钟定义，不是20/40日ATR：

1. `model_control_zero`（原模型、零门槛）：满足T+1后，继续一天预测不高于0即发退出意图。
2. `model_control_negative`（原模型、负门槛）：继续一天预测不高于-0.10%即发退出意图。
3. `matched_horizon`（到期退出）：达到该开仓模型预测的3或5个实际交易日、原买入信号同刻，发退出意图；不使用持仓模型。
4. `minimum_horizon_zero`（到期后零门槛模型）：到期前不启用模型退出，到期后每个采样点由原持仓模型按0门槛判断，不保证到期立即退出。
5. `minimum_horizon_negative`（到期后负门槛模型）：同上，模型门槛为-0.10%。
6. `next_day_control`（最早T+1时间对照）：次交易日首个采样点发退出意图，不用持仓模型。

原模型和到期后模型两类均另有20交易日时间保护。到期退出不使用引擎的3/5日开盘保护，否则会比对应标签的同刻出口过早。所有模式的ATR都可提前发出保护意图，不能为了达到最短持仓而屏蔽止损。T+1及下一分钟执行仍有效；无量、缺行情、跌停代理、容量不足会延迟或部分卖出，待平仓意图不丢弃。换出股票池不构成退出条件。

例如周四13:49信号、13:50买入，3交易日期限在下周二13:49发意图、13:50尝试卖出；这不是周日卖出，也不是周二开盘卖出。周五同票新增批次的到期日则单独顺延。

## 配对与选择

沿用全部4档开仓模型和原3档分位门槛，不拿上一轮外层最好模型作唯一入口。每方法每折4×3×6=72个候选，四折两方法合计576个校准候选。每个候选在3个内部年份片段独立从现金启动；每方法每折前3进入验证，共24个验证候选、72次验证片段回测。

通过条件不变：校准至少20个完整平仓批次才可入围；验证平均夏普为正、至少20完整平仓、至少2个正收益片段，失败则现金。内部验证后不重拟合模型或重新校准门槛。完整四折的平均夏普目标仍为严格大于3，不能删除现金或亏损年。

本轮正式研究在首折选择完成前另记录外层晋级流程：至少一种方法在四折都选出可启用规则，才安排正式外层回顾评价。否则保留内部报告而不观察外层；这只是必要条件，不保证测试有交易或达标。该约束由研究执行流程遵守，CLI不会自动运行测试，不能把内部报告补成假的测试曲线。

`paired_calibration_comparison.csv`（校准配对差异）按方法、模型和分位，与`model_control_zero`比较。相同的是拟议开仓流及门槛；不同退出释放现金的时刻不同，所以实际买单、持仓重叠也可能不同。这是组合政策比较，不是假定所有成交都完全相同的单笔因果实验。

## 调用顺序

在quant根目录执行。不会改原始行情、删除旧报告或连接券商；全量内部对照需要较长时间，只写新目录。

```bash
# 两环境语法及合成回归检查
python3 -m py_compile quant_backtest/exit_alignment.py scripts/run_exit_alignment_year_validation.py
/home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -v

# 使用来源8股票小模型，不重训、不扩展股票数量
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_exit_alignment_year_validation.py --smoke --workers 2

# 复用全部20个正式模型，重新做内部退出对照，默认不进行外层评价
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_exit_alignment_year_validation.py --phase train

# 只读取训练期文件，先冻结审计，再核对副本/原校准复现/外层必要条件
/home/lxl/anaconda3/envs/quant/bin/python scripts/audit_exit_alignment_comparison.py --run-dir reports/exit_alignment_year_validation/run_时间戳

# 仅在满足事前晋级条件的新轮次使用；本轮215813不符合，不执行此命令
# 确认冻结后的一次外层回顾评价，不能误用旧多尺度入口
/home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_exit_alignment_year_validation.py --phase evaluate --run-dir reports/exit_alignment_year_validation/run_时间戳
```

传错入口、缺少期限退出工厂或重复评价会拒绝执行，不会默默换成旧模型退出。只训练时不生成虚假的测试收益图；外层评价后才按标准生成8组中文曲线、逐笔成交、平仓/未平仓、指标与文件说明。`training_report.md`保留内部报告，不因测试主报告生成而消失。

## 配置字段

以下新增字段全部必需、没有隐式默认；值均来自提供的YAML。消费者为`run_exit_alignment_year_validation.py`，退出规则另传给`exit_alignment.py`和原回测引擎。

| 字段 | 提供值 | 作用 |
|---|---|---|
| source_run | reports/multiscale_year_validation/run_20260908_212612_018862 | 正式20模型及输入/日期契约来源，不读取其外层结果 |
| source_run_smoke | reports/multiscale_year_validation_smoke/run_20260908_212513_479010 | 小样本8模型来源，只在--smoke使用 |
| output_dir | reports/exit_alignment_year_validation | 新报告父目录，烟测自动加_smoke后缀 |
| exit_candidates[].name | 上述六个代码 | 稳定候选标识，用于配对和报告 |
| exit_candidates[].alignment_mode | model_control / matched_horizon / minimum_horizon_model / next_day_control | 退出工厂分派，不可缺省退回其他策略 |
| exit_candidates[].initial / .trailing | 20 / 40 | 各对照共同ATR保护倍数，入口检查一致性 |
| exit_candidates[].max_days | 模型20、到期0、T+1对照1 | 与模式必须对应，到期0表示由同刻到期器处理，不是无条件永不退出 |
| exit_candidates[].exit_threshold | 0或-0.001 | 模型继续收益门槛；非模型对照中不用此数值 |

其余数据/因子/模型/费用/开仓门槛网格取自来源`resolved_config.yaml`，不能通过本配置暗改。`--workers`仅一次性覆盖线程数并写入新合并配置。费用仍为万八免5、双边过户十万分之一、历史卖出印花税、单边万五滑点、下一分钟成交额5%容量。

## 复用与限制

来源模型、配置和源码快照均校验哈希。数据、特征、拟合及打分代码不得变化；共用组织器只允许退出工厂、规则选择/评价和报告函数的扩展，其他顶层代码通过AST（语法结构）比较。这个兼容检查不是重算旧模型，也不证明扩展前后退出结果应相同；本轮另存新源码与协议。

共用组织器的源码哈希因此与历史实验不同，历史审计器在当前源码上报不一致属于预期保护。不要修改旧冻结文件来绕过。要复现历史规则须使用其原源码版本；本轮只承诺逐模型文件与来源字节一致，并保存新的退出规则。

研究动机参考[Gârleanu与Pedersen关于预测信号期限和交易成本的研究](https://www.nber.org/papers/w15205)。该论文讨论的最优动态配置及期货验证，不等于这里的A股到期/ATR规则已有效；本研究没有宣称复现其最优解，也不能承诺夏普3。
