# 训练内部选择模型族的统一策略

[2026-09-09正式结果](../reports/family_selected_path_validation/run_20260909_100636_597293/研究结论.md)：完整四年均夏普0.055754，目标未达。
四年收益1.89%、-31.45%、-11.53%、5.29%；2026仅1至4月。冻结之后没有按测试成绩回选，旧模型快照不替换。

## 架构与研究边界

父轮完整核心研究的直接模型与环境分解模型均未各自四折全部内部通过，原结论保持不变。
本轮是在看过父轮内部验证后新增的研究选择，不是原先完全预注册，也不是新的独立样本。
本轮source_method中的method1表示完整核心直接净收益回归，method2表示环境加个股相对收益分解；不是旧XGBoost/CTA实盘快照的名称替换。
新增一个统一算法：每折仅在非留出年份内部验证中，按同一函数选择模型族，选择后冻结再做一次外层。
**不是按测试年度收益选最好的方法拼接，也不能将新结果贴回父轮方法一或方法二。**

流程：未启动外层且已审计的完整核心父轮 -> 内部模型族选择 -> 复制原模型与原门槛/退出 -> 冻结
-> 重新计算选择并核对模型字节 -> 唯一一次四年回顾 -> 收益曲线、逐笔交易、指标和文件说明。
不重新拟合，不重建特征或路径pkl，也不修改父轮失败结论；新增选择会增加研究自由度和过拟合风险。

## 文件角色

| 文件 | 角色和用途 |
|---|---|
| config/family_selected_path_validation.yaml | 用户输入，source_run为未启动外层的父轮，output_dir为新报告根目录 |
| scripts/run_family_selected_path_validation.py | freeze内部选择、audit继承审计、evaluate单次外层入口 |
| tests/test_family_path_selection.py | 高均值不能覆盖片段约束、忽略外层列、行序不变、门槛错配拒绝等测试 |
| scripts/audit_family_path_results.py | 只读六份年度CSV及汇总，独立重算现金/盈亏/费用/持仓/日频指标，写时间戳审计目录 |
| tests/test_family_result_audit.py | 空成交、部分/完全卖出、成本、延迟、T+1、总资产预算及篡改拒绝测试 |
| quant_backtest/pooled_path_models.py | 复用直接或双分量推断，不改已训练模型 |
| quant_backtest/annual_portfolio.py | 复用统一资金账户、独立批次、T+1和成本/容量撮合 |
| reports/family_selected_path_validation/run_*/ | 新策略的冻结模型副本、选择证据、审计与外层结果 |
| reports/family_selected_path_validation_smoke/ | 流程烟测，只验证接口，不用于收益验收 |

每轮输出文件说明.md逐项解释模型、原生分量、父轮完整内部候选、参数与交易记录。
split_audit.csv是父轮全部候选训练来源，只有每折选中的模型被本轮复制，并非本轮重新拟合。

## 选择规则

1. 父轮源码/模型/内部表/配置必须冻结，真实输入及分量重载审计通过；父轮已有test_started.json则拒绝新增选择。
2. 仅考虑全部内部年份片段有波动、平均夏普大于0、至少20完全平仓批次和至少2正收益片段的候选。
3. 在两个模型族的内部候选中按均夏普降序、最差回撤降序、规则名及族名升序择一，函数没有留出年份参数。
4. 候选必须就是父轮已冻结的对应族赢家，门槛必须逐值一致；不重新校准门槛或更换退出。
5. 两族都没有合格候选则现金保护，保留该年；统一算法四折都内部启用才允许正式外层，烟测不用于盈利。

有一折选择直接模型、另一折选择分解模型，是相同训练算法在不同训练资料上的输出，不是人工按年份写切换条件。
但这层算法本身是在看过父轮内部结果后提出的，不能忽略这一额外研究选择及全历史多次研究的问题。
审计继承父轮已经完成的实际特征/目标/权重重建证据，同时重算本轮选择、核对复制的模型及原生分量完全相同；
不会把简单复制写成“又重新训练了四个模型”。

## 交易

上一自然周高波动300只沪深主板周池；每24交易分钟取最高5只且通过冻结门槛才买，每批最多信号时总资产10%。
同股同日不重复买，隔日符合条件且有资金可独立加仓。离池不卖，初始20倍/吊顶40倍简单分钟ATR或对应期限触发退出。
T+1、精确下一分钟、100股、万八免5、历史税费、万五滑点及5%分钟成交额共享容量均与父轮相同。
无法成交或部分成交保留待退出，期末不强制虚构平仓；分解模型的环境和个股预测相加，不存在空头。

## 调用顺序

在quant根目录使用quant环境；先确保父轮--phase audit已通过、且没有启动过外层。

    /home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -q
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_family_selected_path_validation.py
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_family_selected_path_validation.py --phase audit --run-dir 实际新目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_family_selected_path_validation.py --phase evaluate --run-dir 实际新目录
    /home/lxl/anaconda3/envs/quant/bin/python scripts/audit_family_path_results.py --run-dir 实际新目录

freeze会创建独立新目录，复制4个选中模型包，不碰父轮模型；audit核对真实来源证据继承与选择；evaluate只有一次。
烟测用--source-run指定未启动外层的8股父轮，自动写到_smoke目录，不借用正式测试选择模型。
正式全四年均夏普严格大于3才达到目标，无波动或亏损年度不得删掉，内部均值不能代替测试。

已完成目录禁止第二次evaluate。独立审计可重复，不会重跑外层，输出result_audit_*/account_audit.csv、audit.json及审计说明.md。
--run-dir是审计必需CLI输入，无默认；费用/初始现金等只读该目录resolved_config.yaml，不接受改费率重算。
该审计不调用原指标函数，但只证明CSV内部一致，不能替代原始行情、信号时序及真实成交能力核验。

## 配置与限制

source_run必需，默认reports/pooled_path_year_validation/run_20260909_095128_476739；output_dir必需，默认reports/family_selected_path_validation。
两字段都由新入口消费，CLI的--source-run只作单次显式覆盖；所有实际交易配置继承父轮并保存，不能用该选择层暗中修改成本/模型。
resolved_config.yaml的output_dir指向本轮根目录，缓存路径仍指向已有pkl；research_protocol.json记录父轮冻结和审计指纹。

旧entry_strategy_description、model、model_profiles、exit_candidates、fit_deployment_model等继承字段并非本轮有效训练/实盘指令。
实际选中模型为29列直接预测或24列个股加5列环境，见逐折model_*.json和frozen_rules.json；不因继承的旧说明声称本轮训练154列或已经生成实盘模型。

前三折含未来年份训练/选参，2026仅1至4月；当前ST、幸存者、公司行动与复权、撮合代理和反复历史研究仍限制实盘可用性。
新策略即使达到数值目标，也不能因此当作无偏、当年可部署或全新未见样本的实盘证明。
