# 低维与技术信号模型研究说明

## 架构

本轮是新的模型对照，不会替换历史method1（XGBoost排序）或method2（XGBoost加CTA）实盘快照。
新方法一用岭回归预测净收益，新方法二用技术信号的保序回归预测净收益，二者不再共享XGBoost打分。
两者仍共享周池、行情、部分输入与执行限制，不能据此认定收益不相关。

数据链路：原274因子年度pkl -> 有界来源面板（保留232有限原因子、去掉递推/累计列）
-> 固定26列输入 -> 分年核心训练 -> 内部校准门槛/退出 -> 独立内部验证 -> 全部冻结
-> 必要条件通过后单次外层留一年回顾 -> 完整年度收益与交易报告。

本轮不重建274因子，也不复制大型pkl到每个运行目录。固定26列是低复杂度对照，不是宣称原154特征已无用。
包含2026的未来年份训练只能用于用户同意的回顾检验，不是历史当时可交易或完全未见测试。

## 阶段调用

从quant根目录使用Python 3.10的quant环境：

    /home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -v
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_simple_signal_year_validation.py --smoke --workers 2
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_simple_signal_year_validation.py --phase train
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_simple_signal_year_validation.py --phase audit --run-dir reports/simple_signal_year_validation/实际运行目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_simple_signal_year_validation.py --phase evaluate --run-dir reports/simple_signal_year_validation/实际运行目录

1. 单元检查使用合成输入，验证局部契约，不评价真实测试收益。
2. 烟测只取8股、16个模型，验证阶段和报告链路，不代表全市场表现。
3. train先写事前协议和源码快照，再逐折拟合、校准及验证；输出模型、系数/分箱解释、各候选明细、冻结规则和中文报告。默认不生成外层预测。
4. audit按原缓存重建每个模型实际训练行，核对来源、标签、年份、抽样数、模型重载及方法内门槛一致性。不会阅读外层交易或收益。
5. evaluate先校验全部冻结文件/当前代码与缓存。正式运行必须至少一种方法四折均内部启用，且该目录从未启动过外层。烟测可绕过晋级，但报告明确标记无盈利证明。
6. 外层运行才会生成测试集收益曲线、逐笔成交、批次配对平仓、期末持仓、年度指标。没晋级时没有测试图，不能用内部或烟测图补充成正式业绩。

源码变更会使旧运行拒绝通过当前代码评价。应使用该轮source_snapshot对应的代码和环境复现，不能更新旧指纹绕过保护。
joblib与pkl仅加载可信本地产物，不接受来自不可信来源的模型文件。

## 核心训练与标签

- 非留出年的交易日按60%核心拟合、20%校准、20%验证；每段起点隔离7自然日。每条训练标签必须在同一段内结束。
- 留出年本身及之后60个实际交易日不可进入内部阶段，另逐行检查真实来源包络没有触及留出年。核心拟合的特征来源还必须始于该年，防止借用上年内部验证行情。
- H为1、3或5个交易日，标签是信号下一分钟买入、H交易日同钟下一分钟卖出的净收益，包含预设双边成本及历史印花税，截断到正负20%。
- 核心训练每股每天只选择一个事前钟点，由股票代码和自然日的稳定哈希决定；钟点缺行情时不改选其他钟。再按当年交易日序号每H+1日取样，并检查同股标签不重叠。
- 每个训练日总权重相等，避免样本多的日期权重更大。跨股关联及各折年份互换仍存在，这不是独立同分布样本。
- 推断不抽稀，仍在每24交易分钟钟点检查。中位数填补、标准化、回归系数、保序校准只拟合核心训练数据，之后不重训。

## 两类新模型

**岭回归（Ridge）**：26个固定输入包括1/3/5/10/20日动量、5/20日波动和回撤、当日收益/量额百分位、
20/60/120分钟反转、20/60分钟布林位置和资金流、60分钟区间位置、周池环境及本股当日收益。
加入L2惩罚，惩罚参数为配置值乘训练样本数，避免样本规模变化造成惩罚相对强弱漂移。
输出单位为净收益基点，预测时除10000转成收益率。[官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。

**技术信号保序回归（IsotonicRegression）**：先固定交易方向与信号公式，把强度分10个等宽箱，
用核心训练期的日期加权净收益均值拟合单调不下降映射，超出已训练强度范围时取端点，不外推无限收益。
它限制曲线复杂度，不保证强度与真实收益必然单调。[官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.isotonic.IsotonicRegression.html)。

记rank为当时截面百分位，所有公式只读已完成行情：

| 技术族 | 入场资格 | 强度公式 |
|---|---|---|
| oversold_reversal（超跌反转） | 本股当日收益<0 | 0.5×(1-当日收益rank)+0.25×(1-1日动量rank)+0.25×(1-60分钟布林位置rank) |
| pullback_trend（趋势回调） | 当日收益<0、5日动量rank≥0.6、20分钟资金流rank≥0.5 | 0.5×(1-当日收益rank)+0.25×(1-20分钟布林位置rank)+0.25×资金流rank |
| trend_breakout（趋势突破） | 当日收益>0、5日动量rank>0.5 | 0.5×5日动量rank+0.25×60分钟区间位置rank+0.25×20分钟资金流rank |

资格或强度必要输入缺失即禁止该技术族入场，不用未来成交数据补资格。
这些是事前技术假设，不是论文已证明在本地费用/周池下盈利，更不是十个“有效因子”的再次认证。

## 开仓、加仓与退出

沿用上周自然周高波动top300沪深主板池、当前非ST/退名单，以及信号时非一字线和分钟成交额至少20万元。
模型净收益须为非负并超过内部校准门槛，才尝试买前5；每笔最多信号时总资产10%，不是剩余现金10%。
同股同日最多一次新批次，隔日可加仓；每笔加仓都有自己的到期钟、止损价及吊顶最高价。

退出不依赖股票是否仍在目标池，比较：
- matched_horizon（与预测期限对齐）：初始20倍分钟ATR、吊顶40倍分钟ATR，再加H交易日同刻到期退出。
- atr_trailing（ATR吊顶）：相同ATR保护，最长20交易日。没有固定百分比止盈，也没有新训练的持仓退出模型。

ATR是最近240条有效分钟真实波幅的简单均值，不是递推Wilder ATR，也不是240个采样点。
T+1优先于所有卖出信号。达到退出条件只代表下一分钟尝试，不能保证止损价成交；容量不足允许部分卖出并保留剩余批次。

佣金双边万八、免5；过户费双边十万分之一；卖出印花税2023-08-28前千一、之后万五；双边万五滑点。
成交最多占精确下一分钟成交额5%，买卖受前收±9.5%保守代理、缺价缺量限制。总资产/现金/股数由统一账户记账。
这些成本是本项目当前约定，并非向用户承诺券商将按相同费率结算。

## 配置字段

所有新增字段由run_simple_signal_year_validation.py及simple_signals.py消费；本轮完整有效值写入resolved_config.yaml。

| 字段 | 必需/默认 | 作用 |
|---|---|---|
| base_config | 必需，config/bounded_year_validation.yaml | 继承原数据/成本/时钟约束，不要求export环境变量 |
| output_dir | 必需，reports/simple_signal_year_validation | 新报告根目录 |
| simple_horizons | 必需，[1,3,5] | 新模型标签期限；不改entry_horizons缓存键 |
| ridge_penalties | 必需，[0.01,0.1,1.0] | 按样本数归一的L2收缩候选 |
| isotonic_families | 必需，三种技术族 | 预定技术方向，未按外层收益选择 |
| isotonic_bins | 必需，10 | 技术强度0至1等宽箱数 |
| simple_min_training_rows | 必需，100 | 候选核心样本不足则记录不可拟合；烟测10 |
| simple_min_positive_segments | 必需，2 | 校准和验证最低正收益片段数；烟测1 |
| simple_shortlist | 必需，3 | 校准排序后按不同模型去重入围数；烟测1 |
| simple_exits | 必需，两组 | name名称、exit_mode模式、initial初始ATR倍数、trailing吊顶ATR倍数、max_days时间上限 |
| gate_quantiles | 继承，[0.5,0.8,0.9] | 校准合资格非负预测的每钟最大值分位，冻结后原样用于验证/测试 |
| min_closed_lots | 继承，20 | 校准/验证完全平仓批次下限；烟测1 |
| entry_min_net_return | 继承，0 | 预测净收益最低门槛 |
| workers | 继承配置，可CLI单次覆盖 | 科学计算线程数 |
| --phase | 可选，train | train/audit/evaluate，不是持久环境变量 |
| --run-dir | audit/evaluate必需 | 已冻结实验目录 |
| --smoke | 可选，关闭 | 缩减为8股流程检查，不能用于目标验收 |

完整继承字段见[有限窗口重训说明](有限窗口重训说明.md)、[多尺度开仓研究说明](多尺度开仓研究说明.md)
和[年度滚动验证说明](年度滚动验证说明.md)，有效值以本轮配置快照为准。

继承配置中的model、model_profiles、exit_model、exit_candidates、max_features、train_shortlist、cta_blend是旧XGBoost流程参数，
本轮不会用它们训练模型或选择规则；应修改本页simple_*、ridge_penalties和isotonic_*字段。
entry_horizons=[3,5]及虚拟持仓缓存参数保留用于识别既有数据缓存，本轮额外复用原有1日标签。
有界加载器仍读取持仓缓存里的当时量价矩阵，但本轮不拟合持仓退出模型，不把879,929条旧虚拟持仓样本计入新模型训练量。

规则代码示例：ridge_h1_p0.1表示“预测1交易日净收益、惩罚系数0.1的岭回归”；matched_horizon表示“到预测期限同刻退出”，
atr_trailing表示“ATR吊顶退出”，q0.8表示“内部校准每钟最高非负预测的80%分位门槛”。
cash_validation_failed表示“内部验证未达标准而保持现金”，不是程序漏掉该折。

内部诊断表字段：role（校准或内部验证阶段）、method（方法分组）、profile（模型配置）、group（固定预测收益区间）、
rows（完整标签样本数）、predicted（平均预测净收益）、realized_net_label（实际扣费标签均值）、
positive_label_rate（标签净收益为正的比例）。这些标签没有资金占用、待卖延迟和实际容量筛选，不能当组合胜率或收益。
规则表中的closed_lots是完全平仓批次数，positive_segments是正收益片段数，active_segments是有波动片段数，
worst_drawdown是各片段最差最大回撤。未入围的技术族不运行验证，更不能把空的验证表理解成校准没有成交。

## 验收与风险

同一方法必须有完整四年有效夏普，才计算等权均值并判断是否严格>3。某年现金无波动时均值未定义，不能丢年或拼接两个方法的最佳年度。
2026只有1至4月77交易日，短年年化不稳定。历史已被反复研究；旧外层收益不参与本轮拟合/选参，但不能再称为全新未见历史。
当前ST快照、复权/公司行动、幸存者和撮合代理的限制仍在，不能直接根据本轮模型上线实盘。
