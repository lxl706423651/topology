# 执行路径模型研究说明

## 架构

本轮继续寻找具有独立开平仓规则、跨年度有效的A股仅做多策略，不以工程检查通过代替“完整四年平均夏普超过3”。
它是新的LightGBM（梯度提升树）研究，不替换旧XGBoost、CTA或上一轮岭回归的实盘快照。

数据链路：既有有界特征pkl -> 固定29列当时特征 -> 独立入场意图的执行路径标签pkl
-> 四折核心训练 -> 内部校准门槛 -> 不同模型短名单验证 -> 全部冻结和来源审计
-> 晋级后唯一一次年度回顾测试 -> 收益图、逐笔成交、批次配对与期末持仓。

本轮针对的是监督目标与交易行为的差异：固定期限价格涨幅没有描述提前ATR退出、T+1等待、买入失败和部分卖出。
新标签纳入这些行为，但独立意图仍不共享资金/容量，也不保证等于完整组合最终平仓收益。
Numba（数值编译加速）只用于批量计算标签，既有逐批交易引擎仍是对照和正式组合执行器。

## 本轮完成情况

[修正抽样后的实际结论](../reports/pathwise_year_validation/run_20260908_235259_988569/研究结论.md)记录48模型、144校准候选、21入围验证和495次内部片段回测。
方法一只在2023留出折内部通过，方法二前三折通过、2026折失败，正式外层未运行，没有本轮测试曲线，平均夏普3目标未达。
2026的3/5/10日期限核心样本分别345/265/157条进入2023和2024折；82项单元测试及48模型来源/重载审计通过。
旧同步抽样轮仅保留内部记录，不因内部成绩更好回选；源码、模型和冻结原文不覆盖。

## 执行顺序

在quant根目录使用Python 3.10的quant环境：

    /home/lxl/anaconda3/envs/quant/bin/python -m unittest discover -s tests -q
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --smoke --workers 2 --build-only
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --smoke --workers 2
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --build-only --workers 4
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --phase train --workers 4
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --phase audit --run-dir reports/pathwise_year_validation/实际运行目录
    /home/lxl/anaconda3/envs/quant/bin/python -u scripts/run_pathwise_year_validation.py --phase evaluate --run-dir reports/pathwise_year_validation/实际运行目录

1. 单元测试覆盖合成行情，不读取真实外层收益。
2. 小规模build-only构建8股标签并核对12个真实核心案例；重复调用复用同一个标签pkl。
3. 小规模train拟合16个模型，只验证流程；其evaluate可绕过正式晋级门槛生成烟测文件，不能用于盈利验收。
4. 全量build-only复用原年度与有界缓存，新增3/5/10日执行标签，抽90个真实核心案例对照原引擎。
5. 全量train在四折各拟合12个模型，共48个；每个模型只能搭配自己的标签退出规则，以3个校准分位筛选，最多24个候选进入验证。
6. audit重建每个模型的实际核心行，检查来源、潜在标签终点、年份、模型重载以及方法内门槛一致性。
7. evaluate必须满足至少一种方法四折内部均启用，且没有启动过该轮外层。模型/规则/配置/源码和缓存身份改变都会拒绝继续。
8. 正式外层之后才会有测试曲线与交易文件；未晋级不生成假测试图、不借用烟测或旧图。

新代码修改了共享撮合保护和内部选参工具的接口，旧轮次必须用各自source_snapshot对应代码复现。
不能更新旧冻结指纹或把旧成绩贴成新版本结果。

## 标签如何构造

每只股票每个交易日只预定一个采样钟，股票代码和自然日的稳定哈希决定钟点；
该钟没有合格数据时不改选当天其他钟。入口不使用未来价格、成交量、收益或是否成功买入决定。

每个预定入口开启独立初始现金账户，只尝试一次最多总资产10%的买入：
- 信号当前分钟必须合格；下一分钟执行价格、量额和前收必须有效，100股整手，遵守费用和容量。
- 不能买入则该意图的账户收益为0，而不是事后删除“不好成交”的意图。
- 每批初始20倍、吊顶40倍简单分钟ATR；到3/5/10交易日同刻也产生退出信号，离池不卖。
- 满足T+1后下一分钟尝试退出；缺价、涨跌停代理及容量不足会阻挡、延后或部分卖出。
- 最多观察到预测期限H加5交易日宽限的同刻。尚未平仓的残余以窗口末市值估值，不虚构强制卖出。
- 原始标签为窗口内净权益变动除以独立初始现金。拟合时截断为正负2%账户收益，即原20%标签截断×10%入场预算。

窗口末市值不是最终成交价，宽限期也不是正式策略强制清仓时间。
不同标签是相互独立的虚拟账户，正式组合则共享现金和容量，不能把标签均值当组合收益。

来源隔离延续原有规则：留出年及之后60实际交易日不进入该折内部；逐行来源不得触及留出年；
核心特征来源不得借用上年内部验证行情。非留出年的核心/校准/验证仍按60%/20%/20%交易日切分，每段起点隔离7自然日。

**即使交易提前平仓，潜在的H+5日标签终点也必须位于同一核心片段。**
这样不会因为一笔交易早早盈利退出，就允许它跨过其他样本必须遵守的训练边界。
再按每H+5+1个当年交易日取样，采用由股票代码决定的固定相位错开日期，显式检查同股潜在标签不重叠；
日期权重相等，跨股票关联仍存在。相位不读取收益或其他年份行数，也不选择“表现好的日期”。

初始同步抽样轮run_20260908_233902_844816在外层前被留在内部研究阶段：2023折10日标签本有184个合格核心日期、
2026有2334个入口，但全体同相位后仅11个日期且2026入口全漏掉。模型/来源审计本身通过，不是泄漏；问题是抽样覆盖不足。
因此没有运行该轮正式外层，旧文件完整保留，改为固定股票相位后重新训练。详见该轮抽样覆盖说明.md。

缓存中net_return是原始账户净收益，window_end是潜在窗口终点，observed_end是实际最后读取行情的时刻，
entered_shares是首次成交股数，remaining_shares是窗口末余股，sell_events是卖出事件数，entry_notional是入场金额。
这些字段全部只供标签/审计，不进入29个模型特征，也不决定推断是否保留最新无标签行。

## 两类模型

固定29列包括上一轮26个有限价格、资金流及周池环境特征，再加当前ATR比例、成交额对数和成交量比。
每个英文特征代码都在model_feature_manifest.csv和explanation_*.csv后附中文定义。
LightGBM原生处理缺失，模型不在验证或测试上拟合填补/标准化，也不在验证选门槛后再次重训。

- 方法一（regression，回归）：直接预测截断后的独立意图账户净收益，以基点训练，推断除10000。
- 方法二（classification，分类）：预测该意图净收益大于0的概率p，然后计算p×训练正类平均收益+(1-p)×训练非正类平均收益。
- 非正类包含未成交零收益意图；因此概率不是已成交交易的胜率。类别幅度只从核心训练估计，并随模型冻结。
- 两种方法共享特征、路径标签和交易引擎，不能预设互不相关或把两者最佳年度拼在一起。

按交易路径定义标签的背景可参见[标签方法文档](https://mlfinpy.readthedocs.io/en/stable/Labelling.html)；
模型接口见[LightGBM官方说明](https://lightgbm.readthedocs.io/en/latest/pythonapi/lightgbm.LGBMRegressor.html)。
本轮不是直接复制默认三重障碍策略，没有新增固定百分比止盈；方法文档不提供本地A股净收益保证。

## 实际组合开平仓

继续使用上一自然周高波动top300沪深主板周池和现有非ST/退名称快照资格。
每24交易分钟重新打分，最高5个且超过内部冻结门槛才尝试买入，每次最多当时总资产10%，不是可用现金10%。
同股同日不重复开新批次，隔日允许独立加仓，所有批次共用现金并分别维护止损/到期时间。
卖出不看是否仍在周池/目标前5，只看批次ATR或到期退出条件与T+1；容量不足时部分执行、保留待卖状态。

费用保持双边万八佣金、免5、双边十万分之一过户费、历史日期对应卖出印花税和双边万五滑点。
成交最多占精确下一分钟成交额5%，前收±9.5%为保守阻成交代理。异常或缺失的执行价格、量、额、前收现在全部失败关闭。
仍没有完整历史ST、公司行动、逐笔排队和真实冲击成本，不能称为完全实盘仿真。

以下字段全部由run_pathwise_year_validation.py、pathwise_labels.py或pathwise_models.py消费。
未配置的继承字段见[低维信号模型研究说明](低维信号模型研究说明.md)和[有限窗口重训说明](有限窗口重训说明.md)，本轮有效值写入resolved_config.yaml。

| 字段 | 必需/默认 | 作用 |
|---|---|---|
| base_config | 必需，config/simple_signal_year_validation.yaml | 继承数据、费用和内部选择标准 |
| output_dir | 必需，reports/pathwise_year_validation | 新报告目录 |
| path_cache_dir | 必需，reports/pathwise_year_validation/cache | 可复用路径标签目录 |
| path_horizons | 必需，[3,5,10] | 实际到期退出的交易日数，烟测[1,3] |
| path_exit_grace_days | 必需，5 | 标签额外观察交易日数，不改变正式组合的待卖处理 |
| path_training_phase | 必需，per_symbol | 股票固定相位错开日期；synchronized仅保留旧同步方案兼容，不依据收益选相位 |
| path_initial_atr | 必需，20 | 初始简单分钟ATR倍数 |
| path_trailing_atr | 必需，40 | 吊顶简单分钟ATR倍数 |
| path_audit_cases | 必需，90 | 核心标签与原引擎比较案例数，按期限均分；烟测12 |
| path_model_profiles | 必需，两组 | name为配置名；num_leaves最大叶子、max_depth深度、min_child_samples叶子样本下限、n_estimators树数、reg_lambda为L2惩罚 |
| gate_quantiles | 继承，[0.5,0.8,0.9] | 校准每钟最高非负预测分位，验证/测试原样复用 |
| simple_shortlist | 继承，3 | 每方法按不同模型去重的入围上限 |
| simple_min_training_rows | 继承，100 | 核心样本下限，烟测10 |
| simple_min_positive_segments | 继承，2 | 校准/验证最低正收益片段数 |
| min_closed_lots | 继承，20 | 完全平仓批次下限 |
| label_clip | 继承，0.2 | 乘入场预算比例后作为账户标签截断 |
| model.random_state / workers | 继承，可显式覆盖workers | 模型/抽样种子与CPU线程数 |

模型固定基准为learning_rate=0.03、reg_alpha=1、全部行/列采样；可在path_model_profiles中显式提供同名字段覆盖，并保存到快照。
旧model_profiles、exit_model、ridge_penalties、isotonic_families等不参与本轮模型选择。
entry_horizons=[3,5]、虚拟持仓缓存参数仍用于识别原有界数据，本轮不训练旧持仓模型。

## 验收

校准和验证都必须全部片段有波动、平均夏普>0、至少20完全平仓批次、至少2正收益片段，才启用对应方法。
所有四折冻结后，至少一种方法全四折内部启用，才安排正式外层。
最终必须计算同一方法完整四年有效夏普的等权平均并严格>3，现金或无波动年不能删除，也不能用内部均值代替。

2026仅已有1至4月。前三折允许未来年份训练/选参，2026实际核心贡献以审计为准；
历史已反复研究，因此不能把结果称为全新未见或当年可部署的实盘业绩。
